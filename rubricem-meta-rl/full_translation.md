# RubricEM: 基于评分标准引导的元强化学习策略分解（超越可验证奖励）

**作者：** Gaotang Li（UIUC）、Bhavana Dalvi Mishra（Google Cloud AI Research）、Zifeng Wang、Jun Yan、Yanfei Chen、Chun-Liang Li、Long T. Le、Rujun Han、George Lee、Hanghang Tong（UIUC）、Chen-Yu Lee、Tomas Pfister（Google Cloud AI Research）

**摘要：** 训练深度研究 Agent——能够规划、搜索、评估证据并综合长篇报告的系统——将强化学习推向了超越可验证奖励的领域。它们的输出缺乏标准答案，它们的轨迹横跨大量工具增强的决策，而标准的后训练提供很少的机制来将过去的尝试转变为可复用的经验。在这项工作中，我们认为评分标准（rubrics）不应仅作为最终答案评估器，而应作为贯穿策略执行、裁判反馈和 Agent 记忆的共享接口。基于这一观点，我们提出了 RubricEM，一个评分标准引导的强化学习框架，结合了阶段化策略分解与基于反思的元策略训练。RubricEM 首先通过将规划、证据收集、审查和综合各阶段都依赖自生成的评分标准，使研究轨迹具备阶段感知能力。然后使用阶段结构 GRPO（SS-GRPO）分配信用，该机制使用阶段化评分标准评判来为长程优化提供更密集的语义反馈。同时，RubricEM 训练一个共享骨干的反思元策略，将已评判的轨迹蒸馏为面向未来尝试的可复用评分标准指导。最终的 RubricEM-8B 在四个代表性长篇研究基准上取得了强劲表现，超越了同类开源模型，并接近专有的深度研究系统。

## 1 引言

深度研究 Agent 通过自主规划、搜索、评估证据和综合长篇报告来回答复杂的信息寻求问题。

然而，如何训练这种能力仍不清楚：Gemini 和 OpenAI 的 deep research 等专有系统几乎不透露其方法论，而现有的大多数工作依赖于可验证的搜索代理 [jin2025searchr1; song2025r1searcher; nguyen2025sfrdeepresearch] 或高质量模仿数据 [tongyi2025deepresearch; moonshot2025kimiresearcher; perplexity2025sonardeepresearch]。

端到端 RL 用于长篇研究之所以困难，是因为输出缺乏真值验证，裁判反馈在长篇工具增强的 rollout 中是粗糙且延迟的，而传统的后训练主要将已评判的尝试转化为参数更新，而不产生明确的、可复用的指导。

这引出了本工作的核心问题：

**强化学习如何训练超越可验证奖励的深度研究 Agent，同时实现长程信用分配和从经验中学习？**

评分标准为无法通过精确答案验证的开放任务提供了一个自然的手段 [gunjal2025rubrics; shao2025dr; chen2025rm]。现有工作主要将它们用作裁判侧的标准来为最终响应分配奖励。我们的关键视角是：评分标准应作为贯穿强化学习全过程的共享接口。定义成功的同一套标准可以指导 Agent 的规划和搜索、支持对中间决策的过程级评判、并被蒸馏为可复用的反思以从经验中学习。

基于这一观点，我们提出了 RubricEM，一个评分标准引导的强化学习框架，结合了阶段化策略分解与基于反思的元策略演化。名称 RubricEM 反映了一个受期望最大化（EM）启发的估计-最大化视角 [dempster1977em]：开放性研究任务的潜在结构——什么重要、信用在哪里、应该记住什么——通过评分标准来估计，而评分标准又决定了策略推理、裁判评分和记忆演化。训练则在评分标准约束的估计下最大化任务策略和反思元策略。

RubricEM 首先通过评分标准引导的推理框架实现评分标准引导的策略分解。在规划中，Agent 生成任务特定的评分标准，并将其贯穿于四个阶段：规划、研究、审查和答案综合。这将扁平的长期 rollout 转化为评分标准约束的决策阶段，其中每个阶段定义了不同的决策模式和自然的优化单元。该框架还使评分标准在训练循环中可操作：它们指导搜索和综合，充当裁判的在线策略参考，并产生可蒸馏为可复用反思的结构化轨迹。

在此基础上，RubricEM 使用阶段结构 GRPO（SS-GRPO）分配信用。SS-GRPO 不是将单一的终端得分广播到所有令牌，而是用阶段特定的评分标准对规划、研究、审查和答案分别打分。裁判为每个阶段维护一个演化的评分标准缓冲区，将现有的演化评分标准评估 [shao2025dr] 从最终答案评判扩展到过程级反馈。这些阶段得分定义了更密集的回报，结合了局部阶段质量和下游影响，给 GRPO 提供更细粒度的信用信号，同时保持无评论家。

最终，RubricEM 将经验复用转化为明确的 RL 目标。任务策略和反思元策略共享一个骨干网络：在任务 rollout 被评判后，骨干网络基于查询和原始轨迹采样多个反思候选，同时一个独立的裁判使用任务 rollout 的评判结果为这些候选打分。反思得分在反思令牌上提供辅助 RL 奖励，更新共享参数；最高分的可选反思也被写入 Agent 评分标准库作为自然语言记忆。该库以两种模式约束未来的 rollout：同轮次内优化检索同一查询上一次的反思，跨轮次迁移检索来自相关问题的反思。因此，每次反思既通过参数更新又通过文本更新来提升 Agent。

我们设计了一个高效的异步反思分支来训练这个元策略，与任务策略 RL 并行，而不增加顺序瓶颈，这是先前 Meta-RL 文献中的一个显著问题 [jiang2026metarl]。

这些组件共同产生了 RubricEM-8B，一个经过 1400 步 RL 训练的 8B 深度研究 Agent。图 1 给出了框架概览，图 2 展示了一个具体示例。在四个代表性长篇研究基准上，RubricEM-8B 在同类开源模型中达到最先进水平，以更少的训练步骤超越了强基线 RL 系统，并接近 Gemini 和 OpenAI Deep Research 等专有深度研究系统。在最终得分之外，我们进行了广泛的消融和分析，包括多个 600 步 RL 消融、框架比较、推理缩放和域外短格式迁移。这些结果支持一个超越可验证奖励的长程 RL 的更通用方案：暴露任务结构、向该结构分配信用、将评判过的尝试转化为可复用的经验。

## 2 相关工作

**深度研究 Agent 的后训练方案。** 大多数现有开源深度研究训练工作专注于具有可验证奖励的短答案任务 [jin2025searchr1; song2025r1searcher; chen2025research; jiang2025deepretrieval; zhao2025rsearch; han2025deep]。同时，专有系统主要报告了扩展高质量模仿数据和在可验证短格式设置上的训练 [openai2025deepresearch; google2025geminideepresearch; perplexity2025sonardeepresearch; moonshot2025kimiresearcher]。本文采取了正交方向：使强化学习对开放性、长篇深度研究有效。最接近的工作是 DR Tulu [shao2025dr]，它研究了超越可验证奖励的端到端 RL。我们在此基础上引入了细粒度信用分配和联合训练的元策略演化，在挑战性的长程 RL 过程中提供更密集的学习信号和可复用指导。

**信用分配与基于语言模型的元强化学习。** 最近的 Agent 强化学习工作日益强调更细粒度信用分配的需求 [mousavi2026post; deepseek2026v4; qian2025toolrl; xi2026agentprm; zhang2026reasoning]。然而，这些方法大多在可验证设置中运作，轨迹可被分解为子目标并有可靠的过程级监督。相关工作在 RL 期间训练元策略，常称为 Meta-RL [jiang2026metarl; yang2026mage]。尽管有前景，这些方法通常在可验证或合成任务上评估，且往往在 rollout 之间引入显式依赖，导致显著训练开销。相比之下，本文针对开放性真实世界深度研究任务，其中中间进展和最终答案都不允许简单自动验证。我们通过消除跨 rollout 依赖并设计高效反思训练基础设施来改进元策略训练效率。

## 3 RubricEM

### 3.1 符号与预备知识

我们研究针对复杂信息寻求查询的深度研究 Agent。给定查询 q ~ D，Agent 与工具环境 T 交互并产生轨迹 τ = (a1,o1,...,aT,oT) ，其中 a_t 为第 t 轮的 Agent 输出（文本片段或结构化工具调用），o_t 为工具输出（当未调用工具时 o_t = ∅）。考虑基于语言模型的 Agent 自回归采样下一步 a_t ~ πθ(a_t|h_t)，h_t = (q, a_<t, o_<t)，最终产出基于检索证据的长篇答案。

### 3.2 结构化推理框架

RubricEM 的核心设计选择是对 Agent 轨迹施加显式的阶段结构。"阶段"指轨迹中服务于特定决策角色的语意段落，如规划、证据收集、自我评估或最终综合。在长程研究任务中，这些阶段提供了稳定的高层组织，否则将是嘈杂的令牌级生成。当这些决策模式被压扁为扁平的自回归过程时，轨迹缺乏这种阶段级组织。策略必须仅从局部上下文中推断当前决策模式，这可能导致低效探索和长程上的累积错误 [xu2025cognitive; feng2026environment]。

**定理 1（阶段信息的价值）：** 在假设 1 的温和条件下，定义 V_flat = E[max_a E[U(h,a)|c]]，V_stage = E[max_a E[U(h,a)|c,z]]。如果存在一个正概率的可测集 C0 和两个任务相关阶段，使得对于每个 c ∈ C0，p(z|c) > 0，p(z'|c) > 0，且 argmax_a E[U(h,a)|c,z] ∩ argmax_a E[U(h,a)|c,z'] = ∅，则 V_stage > V_flat。

定理 1 识别了何时显式阶段信息有益。在长程研究轨迹中，同一局部上下文在不同阶段可能需要不同行动——规划、搜索、审查和最终综合。当这些阶段特化的最优行动不一致时，扁平策略在混淆上下文下运作，而阶段感知策略可以调节当前决策模式。这在其发生的任何正概率集上产生严格的价值改进。证明见附录 E.1。

**具体阶段实例化。** 我们实例化了四个评分标准引导的阶段：Plan → Research → Review → Answer。每个阶段由阶段级 XML 标签标记，带有轻量级内部模式。外部框架是顺序的，而 Research 允许局部迭代和原地计划修订。概述见图 3：

**Plan 阶段：** 在 `<structured_plan>` 内，Agent 在 `<analysis>` 中分析用户的显式和隐式需求，将其转化为 `<rubrics>`，然后提出具体的 `<research_plan>`。评分标准指定：(i) 需要收集的信息知识清单，(ii) 最终撰写时分析性标准，(iii) 答案应避免的负面约束。

**Research 阶段：** Agent 迭代发出 `<call_tool>` 行动。每次工具响应后，Agent 执行 `<state_evaluation>` 步骤，比较累积证据与计划和评分标准，决定是否需要进一步搜索，并可选地原地修订计划。

**Review 阶段：** 在 `<review>` 内，Agent 通过 `<rubrics_review>` 将收集的证据映射回评分标准，并准备撰写计划，包括主要论点和章节大纲。

**Answer 阶段：** 在 `<answer>` 内，Agent 综合最终的长篇答案，带引文支撑。

评分标准在 RubricEM 中不仅仅是评估产物：它们在 Plan 阶段生成，可在 Research 阶段修订，并指导后续所有阶段。这种实例化基于三点考虑：第一，它与任务对齐——深度研究自然涉及规划、证据获取、自我评估和综合；第二，显式标准为策略提供了稳定的自我检查目标，呼应了评分标准学习和显式原则方法 [panadero2017review; tai2018developing; bai2022constitutional]；第三，自生成的评分标准在不同 rollout 间变化，为裁判发现更有鉴别力的阶段标准提供了每轮参考。

该框架直接赋能后续 RL 设计：阶段边界定义了 SS-GRPO 信用分配的单位，评分标准约束的轨迹定义了评分标准库的记忆格式。因此，我们不将框架视为格式化热身，而是视为一个 SFT 诱导的结构化先验，为有效 RL 准备策略 [zhang2026good]。

**SFT 蒸馏。** 为了在策略中实例化框架，我们进行了教师-学生蒸馏（教师为 Gemini-3.1-Pro）。每个查询诱导教师产生遵循上述 XML 模式的阶段结构轨迹。由于原始教师轨迹并不总是遵循目标框架，我们应用拒绝采样丢弃违反阶段边界、工具调用语法、引文格式或事实约束的输出。SFT 语料教会 Qwen3-8B 的不只是工具使用和证据引文，还包括阶段纪律和评分标准约束。数据生成和过滤流水线细节见附录 B.2。

### 3.3 阶段结构 GRPO（SS-GRPO）

在结构化框架基础上，我们提出阶段结构 GRPO（SS-GRPO），用于深度研究中更细粒度的信用分配。先前关于过程监督和长程 Agent RL 的工作表明，更密集的过程级奖励可以大幅改善信用分配 [yang2026patching; tan2026hindsight; qian2025toolrl; wu2026demystifying; wang2026subgoal]。然而，在开放性深度研究中，我们没有 oracle 中间奖励：规划、搜索、审查和综合的质量是语义级的、依赖任务、难以自动验证。SS-GRPO 因此利用第 3.2 节的显式阶段边界结合评分标准引导的评判来构建阶段级学习信号，如图 4 所示。

**阶段得分和回报。** 给定查询 q，采样 n 个 rollout {τ_i}_{i=1}^n ~ πθ(·|q)，每个分为 K 个语义阶段；在我们的实例化中，K=4，对应 Plan、Research、Review 和 Answer。令 B_i,k 为 rollout τ_i 的阶段 k 的令牌集，R_i,k ∈ [0,1] 为 LLM 裁判在该阶段评分标准下的得分。SS-GRPO 不是将所有令牌赋予相同最终得分，而是使用因果阶段依赖矩阵 Λ = (λ_k,j)，其中 j < k 时 λ_k,j = 0，λ_k,k = 1，定义 G^Λ_i,k = Σ_{j=k}^K λ_k,j R_i,j。这样每个阶段保留自己的得分，同时从它启用的下游阶段获得信用。终端奖励广播被视为一个特例。

**阶段回报何时有帮助。** 阶段回报的收益取决于一个简单的权衡：中间评判恢复了被终端奖励遗漏的过程信息，但也会引入裁判噪声。附录 E.2 定理 3 形式化了这一直觉：当恢复的中间信号超过累积的裁判误判时，阶段加权信用改进了梯度近似。因此 SS-GRPO 不需要 oracle 过程奖励，只需要充分对齐的阶段级评判且噪声有界。这引出了下面的阶段演化评分标准裁判。

**阶段演化评分标准裁判。** 如图 4 顶部面板所示，裁判对比同一查询的多个 rollout，为每个阶段提出有鉴别力的评分标准。裁判为 Plan、Research、Review 和 Answer 维护独立的评分标准缓冲区，复用此前高区分度的评分标准，移除不再能区分轨迹质量的条目。由于策略轨迹本身也受评分标准引导，裁判可以利用轨迹生成的评分标准作为参考，同时仍根据裁判侧评分标准缓冲区评分，而不是盲目奖励 rollout 自身的自我评分标准。这使得中间奖励既是阶段本地的，也对当前策略分布自适应。进一步细节见附录 C。

**阶段归一化和目标。** 我们将 SS-GRPO 实例化为 GRPO 的无评论家阶段变体：在每阶段内跨 rollout 组分别归一化回报。同一阶段区块 B_i,k 内的所有令牌共享优势 A_i,k。目标函数保留了 GRPO 的 clip 机制和 KL 散度项。

我们保持评估器无评论家，因为阶段监督是由裁判定义的、在训练中演化的、且从昂贵的长期工具增强 rollout 中收集的——增加一个学习阶段条件评论家将引入显著的额外复杂性。

### 3.4 基于强化学习的元策略训练

超越单轨迹优化，RubricEM 将经验复用作为 RL 的一部分。共享骨干同时作为任务策略和反思元策略：评分标准引导的任务 rollout 提供评判过的经验，反思策略用 LLM 裁判奖励训练以产生可复用的自然语言指导。被采纳的反思进入 Agent 评分标准库供未来检索，使 Agent 同时获得参数 RL 更新和文本记忆更新。这保留了 Meta-RL 从过去经验改进未来 rollout 的目标，同时我们的异步设计避免了顺序的 rollout-反思-更新瓶颈。

**联合训练反思元策略。** 任务策略 rollout 被评判后，我们采样查询-轨迹对，提示共享骨干网络生成多个反思候选，将轨迹视为固定上下文，仅通过反思令牌反向传播。一个特权 LLM 裁判使用原始问题、原始轨迹、阶段化评分标准得分和评估者理由对每个候选打分。这些得分评估每个反思对同轮次优化和跨轮次迁移是否有用；所有候选得分提供反思元策略的 RL 信号，只有最高分的可选反思写入 Agent 评分标准库。由于反思生成器和任务策略共享同一骨干，这个反思侧的目标成为任务策略的辅助 RL 信号，而非纯粹的推理时记忆机制。附录 E.3 形式化了在评判评分标准下的反思更新平均与未来任务改进一致的积极迁移情况。

**耦合的 Agent-裁判共同演化。** 反思循环与第 3.3 节的阶段演化裁判耦合。在线 rollout 暴露新标准和失败模式，更新裁判侧阶段评分标准缓冲区；更新后的裁判同时评分任务轨迹和反思候选。被采纳的反思通过评分标准库回到 Agent，约束未来 rollout。因此，Agent 通过策略和评分标准库更新演化，裁判通过评分标准缓冲区更新而非参数更新演化。

**评分标准库与两种适应模式。** 每条库项将已完成轨迹回顾性地蒸馏为反思评分标准和要点，总结了"试过一次之后什么最重要"。与规划中生成的前瞻性评分标准不同，库项编码了结果感知的经验。它们支持两种适应模式：同轮次优化（检索同一查询自己之前的反思进行重复尝试）和跨轮次迁移（检索来自相关问题过去的反思）。训练中通过两次遭遇课程实现：每个查询先以跨轮次检索求解，后期用新生成的同轮次反思重放，无需额外 rollout 依赖。

**高效异步执行。** 如图 4 底部面板所示，同步实现会阻塞下一步任务 rollout——直到反思生成、反思评判和当前步骤的元策略更新都已完成。我们改为让反思分支滞后一步。在第 N 步，推理引擎运行重工具的任务 rollout，而训练引擎消耗第 N-1 步准备好的反思批次进行元策略更新。第 N 步轨迹评判后，其反思生成和评判任务异步启动，为第 N+1 步准备反思批次。这种一步滞后以精确同步换取更高的基础设施利用率：推理和训练引擎都保持忙碌，元策略训练实际上不增加 SS-GRPO 循环的额外挂钟开销。详细描述见附录 D。

## 4 实验

### 4.1 实验设置

我们在四个代表性长篇基准上评估 RubricEM：HealthBench [arora2025healthbench]、ResearchQA [yifei2025researchqa]、DeepResearchBench (DRB) [du2025deepresearch] 和 ResearchRubrics [sharma2026researchrubrics]。实验基于 DR Tulu 构建，通常共享相同的基础设施、训练数据集、超参数和评估协议。搜索使用 Gemini-flash 驱动的 Google Search 和 Semantic Scholar。训练数据采样自多样的公开查询源，包括 SearchArena [miroyan2025search] 的真实搜索对话和 OpenScholar [asai2024openscholar] 的研究导向问题。SFT 阶段包含短格式和长格式数据，RL 阶段专注于长格式查询。数据集、训练和推理设置、评估协议以及完整基线列表的进一步细节见附录 F。

### 4.2 主要结果

表 1 比较了 RubricEM 与每类中最强的基线。我们尽可能使用已有报告数据或自行复现基线。

RubricEM 在非专有深度研究系统中取得了最高的平均得分 55.5（8B 骨干）。它超越了强开源基线，包括 DR Tulu-8B-RL、Tongyi DeepResearch-30B-A3B 和 WebThinker-32B-DPO。与专有系统相比，在两者都有得分的基准上，RubricEM-8B-RL 平均超越 Perplexity Deep Research，与 OpenAI Deep Research 平均分差距仅 4.4 分，且在 DRB 上表现优于 OpenAI Deep Research。这些结果表明，我们的训练方案可以在小模型规模下产生有竞争力的长篇研究行为。

## 5 实证分析

### 5.1 RL 训练方案消融

我们在固定 600 步预算下消融 RubricEM 的 RL 组件，从同一 RubricEM-SFT 检查点初始化每个运行。比较四个方案：基线 RL（标准的答案级 GRPO）、SS-GRPO（替代终端奖励广播为阶段评分标准信用）、Meta-Policy（保留答案级 GRPO 但添加反思元策略训练和评分标准库检索）、以及全量 RubricEM（SS-GRPO + Meta-Policy）。结果如图 5 所示。SS-GRPO 和 Meta-Policy 均优于基线 RL，全量方案表现最佳。这表明阶段级信用分配和可复用经验学习在相同训练预算下提供了互补增益。

### 5.2 结构化框架与推理时经验复用

我们进一步分析了结构化框架和推理时经验复用。对比结构化与未结构化 SFT 检查点，然后两者都在匹配的 600 步 RL 设置下继续。结构化框架提升了蒸馏质量（图 6a），也使后续 RL 更有效（图 6b）。无框架时 RL 增益小且不稳定。在提示级效果隔离实验中，对 Gemini-3.1-Pro 使用相同搜索后端，我们的框架产出比标准 ReAct 提示更高的 DRB 表现（图 6c），表明结构本身改进了深度研究行为。

推理时经验复用评估：跨轮次复用（检索相关问题过去反思）和同轮次复用（检索同一问题自己之前的反思）均提升 RubricEM 表现（图 6d），而基线 RL 在相同检索设置下没有受益。这表明反思元策略训练学到了可执行的、可复用的指导，而非仅仅是增加提供给模型的上下文量。

### 5.3 短格式基准表现

尽管主要训练长格式数据，RubricEM 在四个短格式搜索基准（SimpleQA、2Wiki、WebWalker、DeepSearchQA）上表现良好。RubricEM-SFT 已学到有效的搜索和回答行为，长格式 RL 进一步提升表现，增益在最复杂任务上最显著。这些结果表明我们的 RL 方案教会了可迁移的工具使用和证据归因技能，而非仅报告撰写。RubricEM-8B-SFT 四个基准平均 67.8，RL 后提升至 73.5，远超 DR Tulu-8B-SFT 的 44.8 和 DR Tulu-RL 的 49.0。

## 6 结论

我们提出了 RubricEM，一个面向超越可验证奖励的深度研究的评分标准引导 RL 框架。RubricEM 结构化长程轨迹、分配阶段感知信用、并通过共享骨干反思元策略将评判过的尝试蒸馏为可复用指导。跨基准和分析，RubricEM-8B 展现了强劲表现，消融支持了每个方案的贡献。进一步讨论和局限见附录 H。

**局限与讨论（附录 H）：** 目前只在 Gemini-flash 搜索后端上验证（未用真实网页搜索）、教师模型受限、反思质量的反馈信号本身由 LLM 裁判产生——如果裁判产生误导性打分，反思训练可能朝着错误方向演化。Agent-裁判共同演化中的共识漂移是一个需要进一步研究的问题。
