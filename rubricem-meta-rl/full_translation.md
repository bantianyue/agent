# RubricEM: 基于评分标准引导的元强化学习策略分解（超越可验证奖励）

## 摘要

深度研究 Agent——能够规划、搜索、评估证据并综合长篇报告的 AI 系统——将强化学习推向了超越可验证奖励的领域。它们的输出缺乏标准答案，轨迹横跨大量工具增强的决策，而标准的后训练机制缺乏将过去的尝试转化为可复用经验的机制。本文认为，评分标准（Rubric）不应仅作为最终答案评估器，而应成为贯穿策略执行、裁判反馈和 Agent 记忆的共享接口。基于这一观点，我们提出了 RubricEM，一个将阶段化策略分解与基于反思的元策略训练相结合的评分标准引导强化学习框架。RubricEM 首先通过让 Agent 在规划、证据收集、审查和综合各阶段依赖自生成评分标准，使研究轨迹具备阶段感知能力。然后使用阶段结构 GRPO（SS-GRPO）分配信用，该机制通过各阶段评分标准评判提供更密集的语义反馈以实现长程优化。同时，RubricEM 训练一个共享骨干网络的反思元策略，将已评分的轨迹蒸馏为面向未来尝试的可复用评分标准指导。最终的 RubricEM-8B 在四个代表性长篇研究基准上取得了强劲表现，超越了同类开源模型并接近专有深度研究系统。

## 1 引言

深度研究 Agent 通过自主规划、搜索、评估证据和综合长篇报告来回答复杂的信息寻求问题。然而，如何训练这种能力尚不明确：Gemini 和 OpenAI 的 deep research 等专有系统几乎没有透露其方法论，而现有的大多数工作依赖于可验证的搜索代理或高质量模仿数据。

端到端强化学习用于长篇研究之所以困难，是因为输出缺乏真值验证，裁判反馈在长工具增强的 rollout 中是粗糙且延迟的，而传统的后训练机制大多将已评判的尝试转化为参数更新，而不产生明确的、可复用的指导。

这就引出了本文的核心问题：

**强化学习如何在超越可验证奖励的前提下训练深度研究 Agent，同时实现长程信用分配和从经验中学习？**

评分标准为无法通过精确答案验证的开放任务提供了一个天然的抓手。现有工作主要将其用作裁判侧的标准来为最终响应分配奖励。本文的关键视角是：评分标准应作为贯穿强化学习全过程的共享接口。定义成功的同一套标准可以指导 Agent 的规划和搜索、支持对中间决策的过程级评判、并被蒸馏为可复用的反思以从经验中学习。

基于这一观点，我们提出 RubricEM，一个结合了阶段化策略分解与基于反思的元策略演化的评分标准引导强化学习框架。名称 RubricEM 反映了受期望最大化启发的"估计-最大化"视角：开放性研究任务的潜在结构——什么重要、信用在哪里、应该记住什么——通过评分标准来估计，而评分标准又决定了策略推理、裁判评分和记忆演化。训练则在评判标准引导的估计下最大化任务策略和反思元策略。

RubricEM 首先通过评分标准引导的推理框架实现评分标准引导的策略分解。在规划阶段，Agent 生成任务特定的评分标准，并将其贯穿于规划、研究、审查和答案综合四个阶段。这将扁平的长程 rollout 转化为评分标准约束的决策阶段，每个阶段定义了不同的决策模式和自然的优化单元。

在此基础上，RubricEM 使用阶段结构 GRPO（SS-GRPO）分配信用。SS-GRPO 不是将单一的终端得分广播到所有令牌，而是用阶段特定的评分标准对规划、研究、审查和答案分别评分。裁判为每个阶段维护一个演化的评分标准缓冲区。这些阶段得分定义了更密集的回报，结合了局部阶段质量和下游影响，在无需额外学习评论家的情况下为 GRPO 提供更细粒度的信用信号。

最终，RubricEM 将经验复用转化为明确的 RL 目标。任务策略和反思元策略共享一个骨干网络：在任务 rollout 被评判后，骨干网络基于查询和原始轨迹采样多个反思候选，同时一个独立的裁判使用任务 rollout 的评判结果为这些候选打分。反思得分在反思令牌上提供辅助 RL 奖励，更新共享参数；最高分的可选反思还被写入 Agent 评分标准库作为自然语言记忆。该库以两种模式约束未来的 rollout：同轮次内优化检索同一查询的上一次反思，跨轮次迁移检索来自相关问题的反思。这样，每次反思既通过参数更新又通过文本更新来提升 Agent。

这些组件共同产生了 RubricEM-8B，一个经过 1400 步 RL 训练的 8B 参数深度研究 Agent。在四个代表性长篇研究基准上，RubricEM-8B 在同类开源模型中达到了最先进的性能，以更少的训练步骤超越了强基线 RL 系统，并接近 Gemini 和 OpenAI Deep Research 等专有深度研究系统。

## 2 相关工作

**深度研究 Agent 的后训练方案。** 大多数现有的开源深度研究训练工作专注于具有可验证奖励的短答案任务。专有系统主要报告了扩展高质量模仿数据和在可验证短格式设置上的训练。本文采取了正交方向：使强化学习对开放性、长篇深度研究有效。最接近的工作是 DR Tulu，它研究了超越可验证奖励的端到端 RL。我们在此基础上引入了细粒度信用分配和联合训练的元策略演化，在挑战性的长程 RL 过程中提供更密集的学习信号和可复用指导。

**信用分配与基于语言模型的元强化学习。** 最近的 Agent 强化学习工作日益强调更细粒度信用分配的需求。然而，这些方法大多在可验证设置中运作，轨迹可被分解为子目标且有可靠的过程级监督。相关工作在 RL 期间训练元策略（常称为 Meta-RL）。尽管有前景，这些方法通常在可验证或合成任务上评估，且往往在 rollout 之间引入显式依赖，导致显著的训练开销。相比之下，本文针对的是开放性真实世界的深度研究任务，其中中间进展和最终答案都不允许简单的自动验证。我们通过消除跨 rollout 依赖并设计高效的反思训练基础设施来改进元策略训练效率。

## 3 RubricEM

### 3.1 符号与预备知识

我们研究针对复杂信息寻求查询的深度研究 Agent。给定查询 q，Agent 与工具环境交互并产生轨迹 τ=(a1,o1,...,aT,oT)，其中 a_t 为第 t 轮的 Agent 输出（文本片段或结构化工具调用），o_t 为工具输出。考虑基于语言模型的 Agent 自回归采样下一步 a_t ~ πθ(a_t|h_t)，最终产出基于检索证据的长篇答案。

### 3.2 结构化推理框架

RubricEM 的核心设计选择是对 Agent 轨迹施加明确的阶段结构。"阶段"指轨迹中服务于特定决策角色的语意段落，如规划、证据收集、自我评估或最终综合。在长程研究任务中，这些阶段提供了稳定的高层组织，否则将是嘈杂的令牌级生成。

我们形式化了显式阶段信息的价值。定理 1 指出：当同一局部上下文在不同阶段需要不同行动，且阶段特化的最优行动不一致时，扁平策略将面临混淆上下文，而阶段感知策略可以调节当前决策模式，从而在任意正概率集上实现严格的价值提升。

**具体阶段实例化。** 我们实例化了四个评分标准引导的阶段：Plan → Research → Review → Answer。每个阶段由阶段级 XML 标签标记，具有轻量级内部模式。外部框架是顺序的，而 Research 阶段允许局部迭代和原地计划修订。

**Plan 阶段：** Agent 在 `<structured_plan>` 中分析用户的显式和隐式需求，将其转化为评分标准，然后提出具体的研究计划。评分标准指定：(i) 需要收集的信息知识清单，(ii) 最终撰写时分析性标准，(iii) 答案应避免的负面约束。

**Research 阶段：** Agent 迭代发出 `<call_tool>` 行动。每次工具响应后，Agent 执行状态评估步骤，将累积证据与计划和评分标准对比，决定是否需要进一步搜索，并可选地原地修订计划。

**Review 阶段：** Agent 通过 `<rubric_review>` 将收集的证据映射回评分标准，并准备撰写计划，包括主要论点和章节大纲。

**Answer 阶段：** Agent 综合最终的长篇答案，附上引文支撑。

评分标准在 RubricEM 中不仅仅是评估产物：它们在 Plan 阶段生成，可在 Research 阶段修订，并指导后续所有阶段的执行。这种实例化基于三点考虑：首先，它与任务对齐——深度研究自然涉及规划、证据获取、自我评估和综合；其次，显式标准为策略提供了稳定的规划和自我检查目标；第三，自生成的评分标准在不同 rollout 间变化，为裁判发现更有鉴别力的阶段标准提供了每轮参考。

该框架直接赋能后续 RL 设计：阶段边界定义了 SS-GRPO 信用分配的单位，评分标准约束的轨迹定义了评分标准库的记忆格式。

**SFT 蒸馏。** 为了在策略中实例化该框架，我们进行了教师-学生蒸馏（教师为 Gemini-3.1-Pro）。每个查询诱导教师产生遵循 XML 模式的阶段结构轨迹，通过拒绝采样丢弃不符合阶段边界、工具调用语法、引文格式或事实约束的输出。SFT 语料不仅教会 Qwen3-8B 工具使用和证据引文，还教会了阶段纪律和评分标准约束。

### 3.3 阶段结构 GRPO（SS-GRPO）

在结构化框架基础上，我们提出阶段结构 GRPO，用于深度研究中更细粒度的信用分配。在开放深度研究中，我们没有 oracle 中间奖励：规划、搜索、审查和综合的质量是语义级的、依赖任务的、难以自动验证。SS-GRPO 因此利用第 3.2 节的显式阶段边界结合评判标准引导的评判来构建阶段级学习信号。

**阶段得分和回报。** 给定查询 q，采样 n 个 rollout τ_i ~ πθ(·|q)，每个分为 K 个语意阶段（本文 K=4）。令 B_i,k 为 rollout τ_i 的阶段 k 的令牌集，R_i,k ∈ [0,1] 为 LLM 裁判在该阶段标准下的得分。SS-GRPO 使用因果阶段依赖矩阵 Λ=(λ_k,j)，其中 λ_k,j=0（j\<k）且 λ_k,k=1，定义 G^Λ_i,k = Σ_{j=k}^K λ_k,j R_i,j。这样每个阶段保留自己的得分，同时从它启用的下游阶段获得信用。终端奖励广播被视为一个特例。

**阶段回报何时有帮助。** 阶段回报的收益取决于一个简单的权衡：中间评判恢复了被终端奖励遗漏的过程信息，但也会引入裁判噪声。附录 E.2 定理 3 形式化了这一直觉：当恢复的中间信号超过累积的裁判误判时，阶段加权信用改进了梯度近似。因此 SS-GRPO 不需要 oracle 过程奖励，只需要充分对齐的阶段级评判且噪声有界。

**阶段演化裁判。** 裁判对比同一查询的多个 rollout，为每个阶段提出有鉴别力的评分标准。裁判维护各阶段独立的评分标准缓冲区，复用之前高区分度的评分标准，移除不再能区分轨迹质量的条目。由于策略轨迹本身也受评分标准引导，裁判可以利用轨迹生成的评分标准作为参考。这使得中间奖励既是阶段本地的，也对当前策略分布自适应。

**阶段归一化和目标。** 将 SS-GRPO 实例化为 GRPO 的无评论家阶段变体：在每阶段内跨 rollout 组归一化回报。同一阶段区块 B_i,k 内的所有令牌共享优势 A_i,k。目标函数保留了 GRPO 的 clip 机制和 KL 散度项。

### 3.4 基于强化学习的元策略训练

RubricEM 将经验复用作为 RL 的一部分。共享骨干网络同时作为任务策略和反思元策略：评分标准引导的任务 rollout 提供被评判的经验，反思策略用 LLM 裁判奖励训练以产生可复用的自然语言指导。被采纳的反思进入 Agent 评分标准库供未来检索，使 Agent 同时获得参数 RL 更新和文本记忆更新。

**非对称执行。** 同步实现会阻塞下一步任务 rollout（需等反思生成、反思评判和元策略更新完成）。我们让反思分支滞后一个 RL 步。第 N 步推理引擎运行重工具任务 rollout，训练引擎消耗第 N-1 步准备的反思批次。第 N 步轨迹评判完成后，其反思生成和评判任务异步启动，为第 N+1 步准备反思批次。这种一步滞后以精确同步换取更高的基础设施利用率。

**联合训练反思元策略。** 任务策略 rollout 被评判后，采样查询-轨迹对并提示共享骨干网络生成多个反思候选，将轨迹视为固定上下文且仅反向传播反思令牌。一个特权 LLM 裁判使用原始问题、原始轨迹、阶段得分和任务评判的评估理由对每个候选打分。所有候选得分提供反思元策略的 RL 信号，只有最高分的被采纳反思写入 Agent 评分标准库。

**评分标准库与两种适应模式。** 每条库项将已完成轨迹回顾性地蒸馏为反思评分标准和要点，编码了"试过一次之后什么最重要"。它们支持两种模式：同轮次优化（检索同一查询自己之前的反思）和跨轮次迁移（检索来自相关问题过去的反思）。训练中通过两次遭遇课程实现：每个查询先以跨轮次检索求解，后期用新生成的同轮次反思重放。

**耦合的 Agent-裁判共同演化。** 反思循环与阶段演化裁判耦合。在线 rollout 暴露新标准和失败模式，更新裁判侧阶段评分标准缓冲区；更新后的裁判同时评分任务轨迹和反思候选。被采纳的反思通过评分标准库回到 Agent，约束未来 rollout。Agent 通过策略和评分标准库更新演化，裁判通过评分标准缓冲区更新（而非参数更新）演化。

## 4 实验

### 4.1 实验设置

我们在四个代表性长篇基准上评估 RubricEM：HealthBench、ResearchQA、DeepResearchBench (DRB) 和 ResearchRubrics。实验基于 DR Tulu 构建，共享相同的基础设施、训练数据集、超参数和评估协议。搜索使用 Gemini-flash 驱动的 Google Search 和 Semantic Scholar。训练数据采样自多样的公开查询源，包括 SearchArena 的真实搜索对话和 OpenScholar 的研究导向问题。SFT 阶段包含短格式和长格式数据，RL 阶段专注长格式查询。

### 4.2 主要结果

RubricEM-8B-RL 在非专有深度研究系统中取得了最高平均得分 55.5。它超越了强开源基线，包括 DR Tulu-8B-RL、Tongyi DeepResearch-30B-A3B 和 WebThinker-32B-DPO。与专有系统相比，RubricEM-8B-RL 在某些基准上超过了 Perplexity Deep Research 的平均表现，与 OpenAI Deep Research 的平均分差距仅 4.4 分。

从结构化 SFT 检查点开始，RL 将平均分从 49.2 提升至 55.5，四个基准均有提升。与最近的 RL 基线 DR Tulu 相比，RubricEM 从更强的 SFT 检查点出发，达到更高最终平均分，且使用更少的 RL 步骤（1400 vs 1900）。

## 5 实证分析

### 5.1 RL 训练方案消融

在固定 600 步预算下消融 RubricEM 的 RL 组件，比较四个方案：基线 RL（标准的答案级 GRPO）、SS-GRPO（替代终端奖励广播为阶段评分标准信用）、Meta-Policy（保留答案级 GRPO 但添加反思元策略训练和评分标准库检索）、以及全量 RubricEM。SS-GRPO 和 Meta-Policy 均优于基线 RL，全量方案表现最好，表明阶段级信用分配和可复用经验学习在相同预算下提供互补增益。

### 5.2 结构化框架与推理时经验复用

对比结构化与非结构化 SFT 检查点后继续 RL（600 步）。结构化框架提升了蒸馏质量，也使后续 RL 更有效。无框架时 RL 增益小且不稳定。在 Gemini-3.1-Pro 上隔离测试提示级效果：同样搜索后端下，框架相比标准 ReAct 提示获得更高 DRB 表现。

推理时经验复用评估：跨轮次复用（检索相关问题过去反思）和同轮次复用（检索同一问题自己之前的反思）均提升 RubricEM 表现，而基线 RL 在同一检索设置下没有受益，表明反思元策略确实学到了可执行的复用指导。

### 5.3 短格式基准表现

尽管主要在长格式数据上训练，RubricEM 在四个短格式搜索基准（SimpleQA、2Wiki、WebWalker、DeepSearchQA）上表现良好且呈正迁移。长格式 RL 进一步提升短格式表现，表明 RL 教会了可迁移的工具使用和证据归因技能。

## 6 结论

我们提出了 RubricEM，一个针对超越可验证奖励的深度研究的评分标准引导 RL 框架。RubricEM 结构化长程轨迹、分配阶段感知信用、并通过共享骨干反思元策略将已评判尝试蒸馏为可复用指导。在多个基准和分析中，RubricEM-8B 展现了强劲表现，消融实验支持了每个提出的方案。
