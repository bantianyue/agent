S# 把关键路径压进 720MB 片上 SRAM
T 这条 trace 本身已经越过 400：不交付最终 token 日志时，trace 重放到 **402.6 token/s**；而项目记录里最强的全 DRAM 端到端结果大约 **260 token/s**。围绕 Blackhole 的片上 SRAM 做优化，把系统推进了另一个性能档位。
F fig01.png|图1：解码吞吐对比：仅走 DRAM 的路径与 SRAM+DRAM 路径
T 这里是 batch one。没有投机解码，没有草稿模型，没有跳层，每个用户的数字里也没有藏着第二条流。一个 token 要穿过全部 28 层、最终归一化、语言模型头、全局 argmax 与设备端反馈，下一个 token 才开始。
T 我们用了与高性能 NVIDIA 代码同一族的优化：**kernel 融合、异步预取与双缓冲、精细分片的数据流、设备端状态、trace 图重放**，对应 CUDA 里的自定义 kernel、TMA 式搬运与 CUDA Graphs。DRAM 路径和 SRAM 路径都做了这套处理。
T SRAM 是额外的杠杆。与其每个 token 都把关键数据重新取一遍，不如把它放在使用它的 Tensix 核心旁边。
T 但 Marco Nano 按当代基础模型的标准看很小。这正是重点。我们手上只有四颗 Blackhole，于是把模型缩小到关键解码路径能装进可用片上内存。Tenstorrent 的扩展方向相反：加芯片、加 SRAM、加内存带宽、加算力，同时保持编程模型不变。几周后我们会拿到 32 芯片的 Galaxy Blackhole，开始把同样的思路用到基础模型上。
T Tenstorrent 已经公布过 **DeepSeek-R1-0528 在 100K 上下文下跑到 350 token/s**，跑在 Galaxy 超集群上。Marco Nano 是那个结果为什么在架构上成立的桌边证明。
T 这正是 Tenstorrent 能把性能推向 NVIDIA 以 HBM 为中心的系统未曾针对过的方向：把机器放大到关键路径能装进分布式 SRAM，然后不再做那趟昂贵的外部内存往返。

S# Tenstorrent 构建了什么
T 大多数做 AI 的人了解 NVIDIA，但很少有人知道 Tenstorrent 处理器内部是什么样，所以值得从硬件讲起。
T Blackhole 是由两套片上网络连接起来的 Tensix 核心网格，每个 Tensix 核心由五部分组成：
B **基于 tile 的矩阵引擎**，负责矩阵运算。
B **向量引擎**，负责向量运算。
B **可编程 RISC-V 核心**，既做计算，也负责数据搬运。
B **本地 SRAM**，即每颗核心自己的一小块高速内存。
B **硬件管理的环形缓冲流控**，让数据在核心之间顺畅流动。
T 两个用户可编程的数据搬运 kernel 可以发起异步读写、寻址 SRAM 与 DRAM 存储体、通过信号量协调，并在计算 kernel 工作的同时搬运数据。
F fig02.png|图2：Tensix 核心内部结构：RISC-V 控制核、计算单元与本地 L1 内存，经 Router 接入片上网络
T 以太网控制器与额外的 RISC-V 核心属于同一套架构，而不是围在周围的附属外设。
T Hot Chips 2024 的 Blackhole 与 TT-Metalium 演讲把芯片称作「独立 AI 计算机」。这是个有用的说法：Blackhole 不只是等主机投喂的矩阵引擎，计算、数据搬运、本地存储、DRAM 控制与网络都是这台机器里可编程的部分。
T 当前的 Blackhole p150 产品提供 **120 个 Tensix 核心、180MB SRAM、32GB GDDR6（512 GB/s）、Block FP8 下 664 TFLOPS**，还有四个 800GbE 端口用于 Blackhole 之间直连。
T QuietBox 把四颗 Blackhole 处理器与一颗 AMD EPYC 主机、512GB 系统内存、4TB NVMe 存储，以及把板卡连成高带宽网格所需的线缆装在一起，定价 **11,999 美元**。
F fig03.png|图3：QuietBox 四芯片聚合资源：480 个 Tensix 核心、720MB 片上 SRAM、128GB GDDR6（2.05 TB/s）、2.66 PFLOPS Block FP8 算力
T 四颗处理器聚合起来大约是：480 个 Tensix 核心、720MB 片上 SRAM、128GB GDDR6（2.05 TB/s）、2.66 PFLOPS Block FP8 算力。这些都归本地所有，并且可以通过 Tenstorrent 的开源软件栈完全编程。

S# 为什么 LLM 解码通常是内存问题
T 运行 LLM 有两个阶段。**预填充**处理输入提示，许多 token 可以一起评估；**解码**一次生成一个 token，每个新 token 依赖前一个 token，所以在 batch one 时跨 token 的并行工作很少。
T 这改变了机器的平衡。
T 解码时，每个 transformer 层都要把激活的权重应用到一个 token 上。矩阵引擎可以极快地完成所需算术，但矩阵-向量运算对每个取来的权重复用很少。如果这些权重来自外部内存，处理器等待字节的时间会超过做数学的时间。给一条计算引擎正等着被投喂的流水线加算力，没有用。
T 混合专家模型有帮助，因为每个 token 只有一部分专家权重是激活的。但这没有消除问题：共享的注意力权重、被选中的专家、不断增长的 KV 缓存以及其它循环状态，在每一个解码步都必须到达核心。
T 这就是高性能推理软件使用融合、预取、双缓冲、分片与图重放的原因：这些技术减少流量，并让搬运与有用的计算重叠。但只要同样的关键数据每个 token 仍要穿过外部内存接口，那个接口就仍然是天花板。
T 所以硬件问题不只是芯片每秒能执行多少次运算，还有芯片能以多快的速度把下一批操作数摆到计算引擎面前。这就是 Tenstorrent 内存赌注的背景。

S# 内存赌注
T 现代 AI 处理器大部分时间在搬张量而不是乘张量。算术单元变快的速度，超过了外部内存投喂它们的速度。
T NVIDIA 用 HBM 应对：通过先进封装把昂贵、极高带宽的内存放在 GPU 旁边。例如 H100 SXM 提供 **80GB HBM（3.35 TB/s）**。这是巨大的片外投喂能力，背后还有成熟的 CUDA 软件栈。
T Tenstorrent 做了不同的取舍：Blackhole 用成本更低的 GDDR6 换取大容量，并把少量极快的 SRAM 分散到计算核心之间。Hot Chips 的演讲让这个差别变得可见：
F fig04.png|图4：Blackhole 按数据搬运模式划分的带宽：SRAM local/sharded 94 TB/s、neighbor/halo 47 TB/s、行列与网格组播 24 TB/s、三跳 16 TB/s、十跳 5 TB/s、DRAM row 512 GB/s、Ethernet column 1 TB/s
T 这些是完整 Blackhole 设计的架构级聚合数字，不是承诺每个 kernel 都能看到 94 TB/s。SRAM 带宽随参与的核心数与数据搬运模式扩展：一个只用八个核心的 kernel 只能看到芯片总量的一小部分，一次正确分片、铺满网格的操作则能释放远高于此的带宽。
T 这个限定正是全部要义。Tenstorrent 不会自动把 SRAM 变成缓存：由程序员或编译器决定张量放在哪里、如何分片、哪些核心消费它、何时可以被覆盖，以及走哪条网络路径搬运。软件承担了更多责任，但也获得了多得多的控制权。
T 好处是，已经在 SRAM 里的张量根本不需要穿过 HBM 或 GDDR 接口。
T <span style="display:block;background:#f5f8fb;border-left:3px solid #0F4C81;padding:10px 14px;border-radius:4px;">The highest-bandwidth memory transaction is the one you stop issuing.<br  />译注：带宽最高的那次内存事务，是你不再发起的那次。</span>

S# 缩小版 Galaxy 实验
T Marco Nano 提供了合适的实验形态：真实的 28 层 MoE，每层 232 个专家，每个 token 选 8 个。它覆盖了注意力、不断增长的 KV 缓存、路由、专家执行、张量并行集合通信与自回归反馈，这些正是大得多的 MoE 也必须做的工作类别。
T 整个模型 80 亿参数，但每个 token 只有约 6 亿参数激活。这让我们可以在四颗芯片上复现内存策略：**把关键的循环注意力与解码状态留在 SRAM，同时从 GDDR6 流式加载被选中的专家权重**。
T 我们确实用了 Blackhole 的原生低精度格式：选定的注意力与语言模型权重用 **Block FP4**，精度门槛允许的地方用 **Block FP8**。这些格式是硬件主张的一部分，不是临时拼出来的 benchmark 技巧。同一套模型架构、全部 28 层、同样的自回归依赖都留在路径里，也没有用投机解码去虚增报告的 token 速率。
T 重要的结果不是这份摆放配方，而是内存层级可以随模型一起扩展。四颗芯片足以在 Marco Nano 上证明这一点，一套 Galaxy 提供 32 颗芯片，多个 Galaxy 再次扩展 SRAM 与算力的规模。

S# 实际改变了什么
T 项目记录里最好的全 DRAM 端到端路径大约 **260 token/s**。围绕常驻 SRAM 数据优化流水线之后，交付路径达到 **397.7 token/s**，吞吐提升约 **53%**；不含最终 token 日志交付的原始 trace 重放达到 402.6。
T 这是最佳流水线之间的对比，而不是说改一个环境变量就能拿到 53%。两条路径都用了融合、预取、trace 重放、分片与设备端执行；差别在于做完这些常规优化之后，各自的访存架构还允许什么。DRAM 路径仍然必须把循环复用的数据搬过外部内存，SRAM 路径可以不再搬它。
T 一个更窄的同层驻留 A/B 实验在 2048 上下文下测到 **1.248 倍**的吞吐提升，这是对内存摆放的干净隔离；397.7 token/s 是围绕它设计完其余数据流之后的整机结果。
F fig05.gif|图5：约 400 token/s 的演示回放。Iceland 副本经过挑选以便让流可见；这是速度可视化，不是模型质量样本
T 这里的头条是体验：
F fig06.png|图6：400 token/s 下不同输出长度的耗时：100 token 约 0.25 秒、1000 token 约 2.5 秒；满速解码一小时约 144 万 token
T 这改变了模型的手感：长答案几乎立刻到达。编程 agent 可以检查、提议、测试、修改，而不必把大半个循环花在等推理上；一次评估可以探索更多提示；研究者可以试更多消融；agent 可以在选定一个分支之前考虑更多分支。
T 高 token 吞吐不只是一个服务 benchmark，它是迭代速度。而迭代速度会复利：如果一个人一小时内能完成两倍有用的模型交互，价值不只是省下的那几秒，而是那些变得足够便宜、因而敢于尝试的额外实验。

S# 为什么 SRAM 不只是带宽
T 区别在于 **staging（暂存）与 residency（驻留）**。
T 每个加速器都在暂存数据。NVIDIA 开发者用异步拷贝、TMA、双缓冲、kernel 融合、CUDA Graphs 以及越来越复杂的运行时，把 HBM 流量藏在计算后面。我们在 TT-Metal 里用了对应的技术：异步 NoC 读、预取、融合 kernel、分片布局、环形缓冲与 trace 重放。
T 但暂存仍然要搬字节，驻留消除了重复的往返。
T Blackhole 的 SRAM 是显式管理的，所以程序决定哪些循环张量留在片上、哪些消费者直接读它们。一旦流水线围绕这个事实来安排，中间拷贝和主机同步就可以随着 DRAM 流量一起消失。
T 这就是 Tenstorrent 硬件背后的软件契约：芯片提供快速本地内存、可编程搬运、计算与网络宽度，程序把它们变成一条连续的流水线。

S# 从四颗芯片到 32 颗
T QuietBox 是这套架构的桌面级版本，Galaxy 才是扩展性论证变得有趣的地方。
T 一套 Galaxy Blackhole 在 6U 机箱里连接 32 颗 Blackhole ASIC。Tenstorrent 公布的数据是 **23 PFLOPS Block FP8 算力、6.2GB SRAM（2.9 PB/s）、1TB GDDR6（16 TB/s）与 32 TB/s 的加速器互联**，起价 16 万美元。四套 Galaxy 的超集群起价 64 万美元，更大的配置通过标准以太网扩展。
F fig07.png|图7：QuietBox、Galaxy 与四 Galaxy 超集群的资源与起价：处理器 4/32/128，片上 SRAM 720MB/6.2GB/24.8GB，GDDR6 128GB/1TB/4TB，Block FP8 算力 2.66/23/92 PFLOPS
T 从 QuietBox 到 Galaxy，价格上涨约 9.2 倍；处理器数量涨 8 倍，SRAM 涨约 8.6 倍，DRAM 容量涨 7.8 倍，算力涨约 8.6 倍。这是同一套编程模型一次非常直接的放大。
T 四 Galaxy 超集群把这个规模扩到 128 颗 Blackhole 处理器、24.8GB 片上 SRAM、4TB GDDR6 与 92 PFLOPS Block FP8 算力，公布起价 64 万美元。这些是聚合资源，不是存在一个平坦内存空间的意思；模型看到的性能取决于它的切分方式、通信模式与摆放。
T 多个 Galaxy 继续扩展这个思路。系统不会变成一个神奇的平坦 SRAM 缓存，而是在更多算力旁边提供更多分布式 SRAM、在 SRAM 旁边提供更多 DRAM，以及更多可以搬运规则张量分片的网络链路。
T 对大 MoE 来说，原则和 Marco Nano 一样：把关键的循环路径留在分布式 SRAM，把更冷的容量从 GDDR6 流式加载，当常驻路径需要更多内存或更大算力宽度时再加 Galaxy。
T 这就是 Tenstorrent 的 DeepSeek 结果为什么重要。它不只是一个挂在大机器上的大数字，而是证明同一套内存层级可以一直扩展，直到一个 6710 亿参数模型的重要工作集拥有足够的片上容量与足够多的并行消费者。

S# 与 NVIDIA 的对比
T NVIDIA 和 Tenstorrent 下的是不同的赌注。
T NVIDIA 围绕 **HBM、NVLink 与极其成熟的专有软件生态**构建了异常强大的加速器。策略是让外部内存尽可能快，然后用缓存、预取、融合与调度把它的搬运藏起来。这做得非常好，但 HBM、先进封装与专有 scale-up 基础设施都很贵。
T Tenstorrent 用标准 GDDR6 提供容量、用计算旁的 SRAM 存放最热的数据、用 RISC-V 做控制、用以太网做 scale-out。p150 板卡目前标价 **1399 美元**，四芯片整机 QuietBox 定价 **11,999 美元**，Galaxy 起价 **16 万美元**。
T 如果一个工作负载必须持续从外部内存流式加载工作集，HBM 的带宽是巨大优势；但当关键路径留在 SRAM 里，比赛的性质就变了。Blackhole 公布的 local/sharded SRAM 数字是 **94 TB/s**，对比它自己的 GDDR6 512 GB/s 和 H100 HBM 的 3.35 TB/s。这些数字描述的是不同的访问模式，但它们展示了 Tenstorrent 正在构建的作业区域。
T 完美的 HBM 预取仍然要把数据搬过 HBM 接口，常驻 SRAM 的流水线不会发起那次事务。NVIDIA 没法靠再来一轮融合解决这个差别，它要么把更稀缺的片上内存分给工作集，要么继续买外部带宽。Tenstorrent 从一大块可编程的 SRAM 起步，并通过增加相对便宜的联网芯片来扩展这块容量。
T 这不是说 QuietBox 在所有工作负载上取代 H100，而是说存在一个性能区域：可以分散到 SRAM 的循环工作集，Tenstorrent 的架构能以 HBM 中心系统难以匹敌、也很难负担的方式参与竞争。
T Marco Nano 说明这件事在个人开发者或小团队买得起的硬件上可达、可测。

S# 每美元性能，也是每美元自由
T 这种所有权以云 benchmark 常常忽略的方式改变经济性：没有按 token 计费的账单，没有 API 提供方施加的速率限制，私有数据不离开这台机器。模型可以整夜跑，生成合成数据、评估提示、搜索 kernel 变体或支撑 agent，没有人需要判断下 100 万 token 是否还在本月预算里。
T 成本并没有消失：硬件、电费、散热、工程时间与维护都是真实的，利用率与模型质量也一样重要。但边际决策从「这次调用值不值得付钱」变成了「这个实验值不值得跑」。对研究与产品开发来说，这种自由很可观。
T AI 基础设施讨论常把经济性简化成每百万 token 成本。这对一门服务生意有用，但对用模型做东西的人不完整。快速、自有的推理一次买到好几样东西：
B 交互延迟低到长输出仍然显得即时。
B 吞吐足够跑宽评估，而不是抽查。
B 可以在本地生成训练与合成数据。
B 为 agent 与内部工具提供可预测的容量。
B 专有代码、文档与客户数据的隐私。
B 能修改完整软件栈，直到 kernel 层。
B 不依赖提供方的模型可用性、定价或使用政策。
T 在约 400 token/s 下，一条连续流的理论上限约为**每小时 144 万 token**。真实利用率会更低，真实工作负载还包含预填充、批处理与编排，但这个数字仍然大到足以改变行为：小团队不再需要配给推理，可以把它当成一种本地资源。
T 这也许是 Tenstorrent 最有意思的每美元性能论点：硬件便宜到可以拥有，快到足以改变开发循环，并且当工作负载超出桌面时，扩展不需要替换编程模型。

S# 下一个规模
T QuietBox 实验回答了问题的小版本：循环工作集可以留在 Blackhole SRAM，选定的冷权重可以从 GDDR6 流式加载，由此得到的全 token 流水线能在小 MoE 上接近 400 token/s。
T Galaxy 让我们问大版本的问题：基础模型的共享工作集有多少能常驻在 32 颗芯片上？上下文增长时 KV 应该如何分布？专家预取应该在哪里与注意力重叠？多大的批处理能提升 tile 利用率而不牺牲每用户延迟？多套 Galaxy 互联时，哪些张量应该移动，哪些永远不该离开它们消费者旁边的 SRAM？
T 这些是由硬件选择开启的软件问题。
T 以 HBM 为中心的系统问的是加速器能以多快从计算网格之外的内存继续取张量；Tenstorrent 问的是这些取回能消掉多少，然后提供随系统增加而增长的 SRAM 与网络容量。
T QuietBox 让这套架构以 1.2 万美元变得可获得，Galaxy 把同样的想法带到基础模型规模。
T 令人兴奋的不是 SRAM 本身，而是当快速内存、可编程数据搬运、便宜容量与 scale-out 被视为一台计算机，并且这台计算机便宜到可以拥有时，会发生什么。
