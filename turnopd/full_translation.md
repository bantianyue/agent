# TurnOPD 完整中文翻译

## 标题
**TurnOPD：让在线策略蒸馏（On-Policy Distillation）具备「回合感知」能力，实现高效的长程智能体训练**

作者：Yuhang Zhou（复旦大学、腾讯混元）、Kai Zheng（腾讯混元）、Haoling Li（腾讯混元）、Dengyun Peng（复旦大学）、Can Xu（腾讯混元）、Jingjing Chen（复旦大学）

## 摘要
在线策略蒸馏（OPD）通过让学生策略在其自身轨迹上匹配一个更强的教师模型，来训练学生策略，为语言智能体（language agent）训练提供了一个有前景的框架。然而，它在长程智能体任务上的应用仍然未被充分探索。我们识别出原始智能体 OPD 中两个关键低效问题：(1) 全程（full-horizon）rollout 往往在尾部回合（tail turns）上浪费时钟资源，而这些尾部回合提供的反向 KL 监督既微弱又嘈杂；(2) 轨迹级别的 KL 目标把大部分损失集中在浅层 token 上，导致一旦初始行为对齐之后，更深的决策回合得不到充分训练。为应对这些挑战，我们提出了 **TurnOPD**，一种面向长程智能体高效在线策略蒸馏的回合级预算（turn-level budgeting）策略。TurnOPD 由两个预算控制器组成：自适应 rollout 深度预算，利用基于探针的回合统计来决定 rollout 长度；以及渐进式回合归一化损失预算，逐步将 KL 加权从 token 级转向回合均衡的监督。在 ALFWorld、WebShop 和 Multi-Hop Search 上、使用任务专用教师模型的实验表明，TurnOPD 在相等的时钟训练预算下取得了更优的验证准确率，并将准确率—时间前沿（accuracy–time frontier）推进到原始 OPD 之外。

## 1. 引言
语言模型正越来越多地被部署为智能体，用于规划、工具使用和环境交互。在线策略蒸馏（OPD）为这类智能体模型提供了一个有前景的训练框架，即学生采样 rollout，一个更强的教师在被访问的状态上通过反向 KL 目标进行监督。这使得监督保持在策略上（on-policy），并提供密集反馈，同时避免了稀疏奖励信号。

然而，将 OPD 应用于长程智能体任务是困难的，因为这些任务不只是简单的序列生成问题。智能体 rollout 涉及多个回合、工具调用、环境变化和状态改变。早期决策影响所有后续状态，而后面的回合往往包含关键但稀少的决策，因此仅靠 token 级反馈可能无法为所有关键点提供恰当的监督。

我们对长程智能体任务中的 OPD 进行了系统性分析，追问：监督信号和优化预算是如何沿着交互轨迹分配的，又带来了什么后果？我们的诊断识别出两个主要问题：(1) 每回合 KL 分布：反向 KL 信号严重偏向早期回合，随训练而变化，并对更深的步骤变得信息量更低。学生和教师的输出常常随着更多上下文被自我生成而趋同，从而即使在存在有意义分歧时也会降低观测到的 KL。(2) 损失预算：优化器的损失分配并不公平，浅层回合被过度代表且携带更高的 KL，因而主导了损失，而深层回合贡献甚微。例如，在 ALFWorld 上，最深的第三个回合只分配到 3.6%–4.5% 的 KL 损失，在 Multi-Hop Search 上为 11%–13%。虽然严格的回合级归一化可以缓解这一问题，但它会冒险过度加权深层、低数据的回合。总体而言，沿完整轨迹的标准 KL 监督和归一化是不充分的。

这些问题源于两个错配：(1) 外部错配：固定的 rollout 深度忽略了纠错信号和存活数量（survivor count）随回合的显著变化。一直计算到最大视野（horizon）浪费了在信号不可靠的步骤上的算力。(2) 内部错配：轨迹级归一化给所有 token 相同的权重，把 KL 信号集中在简单、浅层的回合，并在模型学会了基本交互模式后让深层、有信息量的回合挨饿。

为应对这些，我们提出 **TurnOPD**，一种面向长程智能体高效在线策略蒸馏的回合级预算策略。TurnOPD 由两个预算控制器组成。自适应 rollout 深度控制器通过周期性探针动态选择 rollout 长度，以存活者加权的 KL 和覆盖率阈值为指导。渐进式回合归一化损失控制器逐步将 KL 损失聚合从轨迹级过渡到回合均衡，增加对深层回合的权重。

我们在三个代表性的多回合智能体基准上评估 TurnOPD：具身规划（ALFWorld）、网页导航（WebShop）和 Multi-Hop Search（包含 PopQA、NQ、2WikiMultiHopQA、HotpotQA）。TurnOPD 在所有任务和模型上提升了最小时间 Avg@4。例如，在 ALFWorld-1.7B 上，它将 Same-Step Avg@4 从 83.0 提升到 86.3，并把 100 步的时钟时间从 4.42 小时削减到 1.93 小时。在 WebShop 上，准确率和时钟时间都得到了改善（从 1.57 小时到 1.24 小时）。我们的消融实验进一步支持这一分解。自适应深度是主要的效率杠杆：在 ALFWorld-1.7B 上，它几乎将时钟时间减半，但本身并不能解决损失分配问题；而线性 KL 混合通过将监督重新分配到更深的回合，提升了 Same-Step Avg@4。两者结合给出最佳的准确率—时间权衡，覆盖率下限研究表明该控制器可以在保守和激进的 rollout 视野之间平滑调节。

总结而言，我们的贡献如下：
- 我们提供了对长程智能体 OPD 的回合级分析，揭示了监督和优化信号在决策回合上的普遍分布。
- 我们形式化了长程智能体任务中 OPD 错配现象的一个「污染—压缩」（contamination-compression）机制，并论证了潜在最优 rollout 视野的存在。
- 我们提出了 **TurnOPD**，它结合了自适应 rollout 深度预算与渐进式回合归一化损失预算。
- 我们证明 TurnOPD 在所测基准上取得了最佳的「最少时间」准确率，推进了准确率—时间前沿。值得注意的是，TurnOPD 以最高 2.29× 更快的训练取得了相当甚至更好的表现。

## 2. 相关工作
**在线策略蒸馏。** 早期工作如 MiniLLM 和 GKD 为 LLM 引入了 OPD 方案：MiniLLM 在学生生成的样本上应用反向 KL 训练，而 GKD 混合了在策略与离策略数据并探索了多种散度目标。后来的工作将 OPD 视为 KL 约束的策略优化，以师生 log-ratio 作为 token 级奖励，启发了稳定目标分布、考虑教师熵或放松模仿约束的方法。诊断研究指出长轨迹上的密集监督可能不可靠。尽管如此，多数工作把每个样本视为单一响应，而长程智能体需要更细的粒度。TCOD 引入了轨迹长度的课程，SOD 在步骤级重新加权工具辅助推理的蒸馏，二者都强调面向智能体的 OPD 需要的远不止一个扁平的序列目标。我们的工作是对这些的补充：分析跨回合的 rollout 和梯度分配，并相应地调节 rollout 深度和损失。

**长程智能体任务。** 智能体基准已从受控交互环境转向真实计算机使用任务。ALFWorld 将文本规划与具身环境连接，WebShop 研究接地（grounded）的电商导航。后来的网页和 GUI 基准将设定扩展到真实网站和桌面或移动界面，包括 Mind2Web、WebArena、OSWorld 和 AndroidWorld。近期的评估进一步面向实际工作：SWE-bench 衡量基于 GitHub issue 的仓库编辑，Terminal-Bench 评估命令行工作流，BrowseComp 衡量持久网页研究，TheAgentCompany、GDPval 和 ClawBench 趋向专业或日常在线任务。在这些设定中，共同结构不是扁平响应，而是带有外部观测、变化中的动作有效性、以及跨回合变化的活动轨迹集合的有状态交互轨迹。

## 3. 预备知识：在线策略蒸馏
**多回合智能体交互。** 我们考虑一个学生智能体与外部环境进行多回合交互。在回合 t，智能体观测 o_t，以完整历史 h_t 为条件，并生成模型响应 r_t。响应可能包含推理文本和工具参数。环境随后将 r_t 的可执行部分映射到下一个观测 o_{t+1}。因此一个 rollout 是一个交互轨迹，在任务完成、环境返回终止状态或达到最大视野时终止。这种回合结构很重要，因为学生早期动作改变了之后的观测，从而改变了教师将被查询的未来上下文。

**多回合 OPD。** 我们使用在线策略蒸馏（OPD）：学生为提示 x 采样其自身 rollout，一个冻结的教师 π_T 在学生访问的前缀上提供 token 级监督。这不同于离线蒸馏，因为教师是在由当前学生诱导出的历史上查询的，而不只是教师生成的演示之上。对于拼接后的模型响应中的 token 位置 i，令 s_i 表示该 token 之前的完整前缀，OPD 目标使用反向 KL。

## 4. 诊断：智能体 OPD 中的信号结构
长程智能体 OPD 仍然在生成的序列上优化一个教师匹配损失，但这个序列同时也是一条交互轨迹。本节给出对「智能体 OPD 中监督如何表现」的回合级分解诊断，聚焦于教师信号出现在哪里、它多可靠地分离结果、以及它获得了多少损失预算。

### 4.1 原始回合级 KL 暴露出非均匀的监督
我们提出一个互补的问题：反向 KL 监督本身是如何跨回合分布的？我们首先做最少加工的测量：原始 OPD 下每个模型回合的平均反向 KL 信号。

**设置。** 我们使用 ALFWorld 和 Multi-Hop Search 作为示例任务。两个诊断都使用 100 个优化步的原始 OPD：ALFWorld 用 Qwen3-4B 学生（从 Qwen3-8B-GRPO 教师蒸馏），Multi-Hop Search 用 Qwen3.5-2B 学生（从 Qwen3.5-9B-GRPO 教师蒸馏）。回合级均值只在到达每个回合的轨迹上计算。

**结果。** 图显示了每个模型回合的平均反向 KL 信号。可见两种模式。第一，教师不确定性本身是依赖于回合、依赖于任务的。在 ALFWorld 上，更深的回合往往有更低的教师熵。Multi-Hop Search 显示出不同的熵分布：后面的回合可能有更高的教师熵，但反向 KL 曲线仍然前载（front-loaded）。第二，反向 KL 信号在非平稳的、非均匀的，并随训练变化。在 ALFWorld 上，早期回合起始时有大得多的 KL，然后在前 20–30 个优化步内快速下降，而一长串后期回合保持更低且更嘈杂。Multi-Hop Search 显示出更短但仍有结构的分布：前几个回合有最大的 KL，其余在前对齐期后落入更窄的带。直接结论是，原始智能体 OPD 不能被单一平均 KL 所诊断。然而，每回合的 KL 趋势本身是有歧义的：后期回合的衰减既与真正的对齐一致，也与教师信号失去判别力一致。我们接下来直接检验后者。

### 4.2 结果分离在深度处退化并反转
在多回合设定中，原始 KL 不一定是剩余师生策略差距的可靠代理。因此我们问一个更面向结果的问题：在每个回合，KL 能否区分最终成功的 rollout 与最终失败的 rollout，这种区分如何随回合索引和训练阶段演化？为此定义 G_t = K_t^fail − K_t^succ，其中 K_t^fail 和 K_t^succ 是分别在失败和成功轨迹上单独计算的每回合反向 KL 均值。

图评估了局部 KL 是否能区分成功与失败轨迹。G_t 的符号随任务而变，但二者都显示深层回合 KL 缺乏结果预测力。在 ALFWorld 上，G_t 大多为负并随深度递减：成功轨迹往往比失败轨迹有更高的每回合 KL，尤其是在后面的回合。如果 KL 反映局部纠错需求，这违反直觉，因为失败 rollout 应该需要更多纠错。我们将其归因于「分支依赖的压缩」：失败 rollout 很快陷入循环或模板化模式，两个模型都觉得下一 token 预测很平凡，从而人为降低 KL。相反，成功 rollout 访问更多样化的状态，教师的纠错更少被压缩。

在 Multi-Hop Search 上，差距具有预期的正号：失败轨迹有更大的 KL。然而这种分离大多出现在早期回合。在后面的回合，差距缩小，表明 KL 的判别力集中在前端并随深度减弱。

### 4.3 一个「污染—压缩」机制
上述两个测量留下一个特定的歧义。原始反向 KL 沿可靠的回合前缀递减，其结果分离力也随深度减弱，甚至反转。因此一个小的后期回合 KL 有两种不同的解释：学生可能已经学会了教师，或者学生生成的上下文可能让两个模型在策略级偏好仍有分歧时遵循相同的局部延续。我们用一个污染—压缩模型来形式化这种歧义。

**设置。** 考虑模型回合 t 中的一个被监督 token 位置，令 c 表示该 token 之前的完整在策略上下文，包括之前的学生输出和环境/工具观测。令 π_S(·|c) 和 π_T(·|c) 为同一上下文下学生和教师的下一 token 分布。在回合 t 可观测的原始 KL 为 K_t = E_{c~C_t}[KL(π_S(·|c) ‖ π_T(·|c))]，其中 C_t 是在回合 t 收集到的被监督 token 上下文的经验分布。

对于一个固定的上下文 c，假设下一 token 分布的一部分几乎被上下文本身强制决定：重复字符串、格式约束、复制的实体、闭合分隔符，或两个预训练语言模型都赋予高概率的低层延续。令 p_F(·|c) 表示这个共享的被强制组件。剩余质量包含自由组件，学生和教师可能在这里真正分歧。我们写 π_S = λ(c)p_F + (1−λ(c))p_S^free，π_T = λ(c)p_F + (1−λ(c))p_T^free，其中 λ(c)∈[0,1] 是上下文强制质量。定义潜在自由组件分歧 Δ_free(c) = KL(p_S^free ‖ p_T^free)。

**命题（污染压缩）：** 在上式分解下，KL(π_S ‖ π_T) ≤ (1−λ(c))·KL(p_S^free ‖ p_T^free)。

该命题表明为何原始 KL 不能被识别为纯策略分歧。如果 Δ_free(c) > 0，原始 KL 捕捉到的自由分歧的可观测比例满足 ρ(c) = KL(π_S‖π_T)/Δ_free(c) ≤ 1−λ(c)。因此高的强制质量 λ(c) 即使在自由组件分歧仍然非零时也能压缩测得的 KL。

**为何深度会增加压缩。** 在学生 rollout 中，回合 t 的上下文包含所有更早的学生输出和工具观测。自回归生成是正自条件的：先前的高概率延续使一些未来延续更可预测，重复或格式锁定的上下文会增加强制质量。它为图中所见的轮廓提供了一个结构性解释：随着 rollout 变长，测得的 KL 可能因 (1−λ(c_t)) 收缩而衰减，而不一定是因为自由组件分歧消失了。

**非对称压缩与差距反转。** 成功/失败差距揭示了一个更强的机制：上下文强制质量在结果分支间不必对称。失败轨迹可能表现出刻板模式，如重复无效动作、在同一子目标上循环、或模板化延续。这些模式正是被强制组件 p_F 捕捉到的低层语言规律性和局部自相关。因此，当教师在失败上下文上被条件化时，其下一 token 分布可能更强烈地锁定在局部延续上，使得平均强制质量在失败 rollout 上系统性地大于成功 rollout：λ_t^fail > λ_t^succ。相反，成功轨迹继续遍历任务状态和观测；它们的上下文保持信息更丰富，因此教师仍必须做出真正的语义决策，强制质量更低。

### 4.4 损失聚合造成浅层预算集中
诊断显示了局部纠错信号沿回合轴出现在哪里，它们没有显示优化器把预算花在哪里。这一区分很重要，因为原始 OPD 是通过原始反向 KL 更新学生的。因此我们审计分配给每个回合的已实现 KL 损失质量。

令一个轨迹包含 T 个被监督模型回合，回合 t 包含 n_t 个被监督 token，token 级反向 KL 损失为 ℓ_{t,i}。标准轨迹级归约给每个被监督 token 相同的基准权重。它在回合 t 的 token 份额是 b_t^traj = n_t/N。已实现的批次 KL 损失质量份额是 s_t^traj = Σ_i ℓ_{t,i} / Σ_{u,j} ℓ_{u,j}。

图显示 KL 损失主要集中在早期回合。在 ALFWorld-4B 上，仅回合 0 就占用了约四分之一的 KL 预算。前三个回合占了近一半。可靠的深层第三个只获得 3.6%–4.5% 的 KL 损失。在 Multi-Hop Search 上，效应较弱，但前三个回合仍占 38%–40% 的预算。可靠的深层第三个只得到 11%–13%。这说得通：并非每个 rollout 都到达深层回合，所以批次中来自深层回合的 token 更少。浅层回合的 KL 损失也更大。结果，KL 损失大多分配给早期回合。这些观察得出两个主要结论：(1) 轨迹级归一化造成预算错配。它可以根据 token 质量和已实现的 KL 质量来花费损失，因此即使后面的回合仍包含纠错信号，也能将大多数更新保留在浅层前缀附近。(2) 硬的回合级替代也可能太粗糙。另一个极端给每个被观测回合相同的总权重。这移除了浅层 token 计数偏差，但也可能忽略可靠性。

## 5. 方法：TurnOPD
基于诊断部分的分析，我们识别出将 OPD 应用于智能体时的两个主要问题。第一，每回合 KL 信号随回合深度急剧下降，尤其是在训练早期。KL 损失被浅层回合主导。这表明不必等到完整 rollout 结束才计算 KL 损失。缩短 rollout 视野可以提升整体训练效率。第二，在收集到一条轨迹后，轨迹级归一化根据 token 计数分配损失质量，一旦浅层交互模式收敛，这种方法可能忽略更深的决策回合。

本节我们提出 **TurnOPD**，一种面向长程智能体高效 OPD 的回合级预算策略。TurnOPD 由两个预算控制器组成。第一个控制器自适应地预算 rollout 深度。第二个控制器渐进式地将 KL 损失分配从轨迹级匹配转向回合均衡的决策精炼。

### 5.1 外部错配：自适应 Rollout 深度预算
诊断中确定的一个关键限制是 rollout 深度与监督有效效用之间的错配：用于数据收集的最优轨迹长度应当同时考虑任务和学生的进度，以最大化每单位成本的监督价值。令 H* 表示这个最优（但不可观测）的 rollout 视野，即给定监督成本能产生最大边际验证改进的深度学习度。H* 的存在性由一个效率—覆盖权衡保证：过浅的 rollout 探索不足，而过深的 rollout 在低信号区域浪费计算。

然而，H* 在训练中无法直接测量。TurnOPD 转而通过综合两个互补信号在线估计它：一个以效率为中心的代理和一个基于覆盖的下界。具体地，我们定义 rollout 深度预算控制器为 H_ctrl = max(H_eff, H_cov)，其中 H_eff 捕捉有效监督的质心，H_cov 强制执行最小任务完成覆盖。

**效率侧质量。** 为构造 H_eff，我们将跨回合的反向 KL 信号视为蒸馏质量的存活者加权分布。原始 KL 作为行为误差测量可能不可靠，但作为可观测的监督价值和成本代理仍然有用。对于每个回合 t，令 K_t 为探针学生 rollout 上的平均每 token 反向 KL，n_t/n_0 为在策略存活概率。我们定义 m_t = [K_t]_+ · (n_t/n_0)，q_t = m_t / (Σ_j m_j + ε)。m_t 估计回合 t 贡献的蒸馏信号期望值，q_t 在所有回合上归一化。质心及其离散投影为 H_eff = round(Σ_t t·q_t)。这个一阶矩统计量自适应响应：当有意义的监督质量集中在浅层回合时，H_eff 保持较浅；当纠正确实尾巴持续到更深回合时，H_eff 相应加深。相对加权确保对绝对 KL 量级变化的鲁棒性。

**覆盖侧下界。** 为防止过度激进的截断，覆盖组件基于成功完成设置一个最小 rollout 深度：H_cov = Q_p(L_succ)，即成功条件完成深度的 p 分位数（p=0.80）。这确保 rollout 足够深以包含至少 80% 的成功轨迹，从周期性探针 rollout 估计。

**动态更新。** 控制器是因果的：它使用周期性全长度探针 rollout 更新 H_eff 和 H_cov 的未删失回合统计，而常规训练步只使用当前上限 Ĥ_k。被截断的 rollout 仍贡献 OPD 更新，但被排除在 rollout 深度估计之外，因为后面的回合未被观测，如果幼稚地包含会偏置统计。周期性全深度探针对于防止偏置和级联漂移至关重要。每次探针快照后，TurnOPD 设置 H_ctrl,k = max(H_eff,k, H_cov,k) 并应用指数滑动平均平滑：H̄_k = (1−α_ema)H̄_{k−1} + α_ema·H_ctrl,k，Ĥ_{k+1} = clip(round(H̄_k)+1, H_min, H_max)。+1 从 0 基回合索引转换到实际 rollout 深度。

### 5.2 内部错配：渐进式回合归一化损失预算
第二个挑战是内部预算错配：使用标准轨迹级归一化，大部分 KL 损失分配给浅层回合，因此深层回合常常收到很少或没有监督，尤其在训练后期，当优化长程决策变得关键时。这在早期是合理的（当时浅层错误主导），但后来妨碍了对更难、更深的决策的纠正。

TurnOPD 通过在轨迹级和回合级归一化之间引入线性混合来补救，在训练过程中转移损失分配。令 n_t 为回合 t 的 token 数（T 为总回合数）。回合 t 的标准轨迹级权重为 q_t^traj = n_t/Σ_j n_j，而均匀回合级权重为 q_t^turn = 1/T。最终权重是线性插值：q_t^blend = (1−α)q_t^traj + α·q_t^turn，其中混合系数 α 绑定到归一化训练进度，例如 α = clip((progress−s)/(e−s), 0, 1)，progress = k/K。

初始时（α=0），损失遵循 token 质量，保证早期阶段的稳定性。随着 α 增长，监督平滑地转移到更平等地覆盖所有回合，显式缓解回合深度不平衡，并实现对深层决策的更好学习。

### 5.3 统一与算法
这两个干预调节互补的资源：rollout 深度决定收集多少交互，损失归一化决定在收集到的 token 上如何分配监督。完整训练算法和所有超参数见附录。

## 6. 实验
我们在三个代表性智能体任务上评估 TurnOPD：ALFWorld（具身文本规划）、Multi-Hop Search 和 WebShop（网页导航），使用三个跨越不同模型规模和家族的师生对。我们测试 TurnOPD 是否在不同环境和模型上取得了更好的准确率—时间前沿。

**学生与教师。** 学生从更强的、任务专用的 GRPO 训练教师蒸馏而来：ALFWorld 使用 Qwen3-1.7B/4B 学生搭配 Qwen3-8B-GRPO 教师；WebShop 使用 Qwen3-1.7B 和 Qwen3-8B-GRPO；Multi-Hop Search 使用 Qwen3.5-2B 和 Qwen3.5-9B-GRPO。所有方法使用相同的 OPD 反向 KL 训练栈。

**基线与指标。** 我们评估三种主要方法：原始 OPD、TCOD-F2B 和 TurnOPD。为公平和全面比较，我们在两种机制下评估：最少时间（Least-Time）—基于任何方法达到 100 训练步所需的最小时钟时间处的准确率比较；同一步（Same-Step）—每个方法在恰好 100 训练步后评估。每个方法的准确率报告为对应截断前最后四个评估点（每个点用 Avg@4 计算）的平均准确率。我们也报告最后四个评估点准确率的标准差。此外，我们包含 GRPO 训练教师模型的表现作为参考点。注意教师准确率仅用于上下文，不作为效率比较的基线。

### 6.1 总体表现
表 1 和图总结了三个长程任务和多个师生对的主要结果。原始 OPD 和 TCOD-F2B 都是强基线，但 TurnOPD 一致地改进了整体准确率—时间权衡。

**准确率。** 在最少时间设定下，在所有任务和模型组合的学生训练方法中，TurnOPD 取得了最高的整体 avg@4。在同一步设定下，TurnOPD 在大多数情况下匹配或超越最佳基线。例如，在 ALFWorld 配 Qwen3-1.7B 学生上，TurnOPD 达到 86.29 avg@4，而原始 OPD 为 83.00，TCOD-F2B 为 80.06。在 Multi-Hop Search 上，原始 OPD 保持小的同一步优势，但 TurnOPD 给出最佳的最少时间准确率，表明它在共享时钟预算下达到了更强的表现。表 2 和表 3 进一步提供了任务特定的细分。在 ALFWorld 上，TurnOPD 几乎在两种学生规模的所有类别上都是最强的学生训练方法。在 Multi-Hop Search 上，TurnOPD 改进了 PopQA 和 2Wiki 并给出最佳整体最少时间分数。值得注意的是，在 Qwen3-4B 学生下，TurnOPD 甚至在整体 avg@4 上超过了 ALFWorld 教师参考。

**训练效率与时钟加速。** 除了准确率，TurnOPD 还减少了训练时间。在 ALFWorld-1.7B 上，TurnOPD 将 100 步时钟时间从原始 OPD 的 4.42 小时减少到 1.93 小时，同时提升了准确率。类似改进出现在 Multi-Hop Search（2.94h vs 4.45h）和 WebShop（1.24h vs 1.57h）。因此 TurnOPD 不仅在共享时钟预算下更准，还大幅加速了原始 OPD。

### 6.2 诊断—控制器对齐
主要结果证实 TurnOPD 有效改进了准确率和计算效率前沿。为进一步验证自适应控制器的有效性，我们检查控制器的行为是否与激发其设计的诊断指标一致。图展示了 TurnOPD 的 rollout 深度适应动态。具体地，我们绘制存活者加权的原始 KL 质心 H_eff（代表效率臂）和成功条件完成分位数 H_cov（代表覆盖臂）。控制器自适应地以每一步这两个量的最大值为目标。在出现足够成功 rollout 之前的初始预热阶段，H_cov 设为零以确保观测到的 KL 质心保持可见。跨任务，我们观察到不同的控制器行为：(1) 在 ALFWorld 上，一旦成功轨迹出现，覆盖约束（H_cov）迅速主导，鼓励更长的 rollout；(2) 对于 WebShop，控制器始终保持适度的覆盖下界；(3) 在 Multi-Hop Search 上，平衡在效率臂和覆盖臂之间动态转移。这些图确认了预期的分工：H_eff 确保非平凡的效率，而 H_cov 防止控制器选择过短的、会限制成功完成覆盖的 rollout。

## 7. 消融研究与分析
上一节证明学习到的控制器追踪了 TurnOPD 设计背后的诊断信号。我们现在转向一个更细粒度的问题：TurnOPD 中的单个预算控制器如何贡献于其整体表现？

我们在 ALFWorld-1.7B（Qwen3-1.7B 从 Qwen3-8B-GRPO 在 ALFWorld 任务上蒸馏）上使用与主实验相同的 100 步协议进行消融研究。分析分三部分。第一，我们解耦两个核心干预以评估每个是否单独有效。第二，我们消融 KL 归一化方案，比较轨迹级、硬回合级和线性回合级归约。第三，我们分析改变覆盖下界的效果，它决定了自适应深度控制器的保守程度。

### 7.1 干预组件分解
**设置。** 我们在 ALFWorld 任务上实验。自适应深度变体应用自适应 rollout 深度预算控制器，同时保持原始轨迹级 KL 归约不变，以测试仅缩短 rollout 深度是否足够。相反，线性混合归一化变体保持全视野 OPD rollout 深度，但用线性回合级归一化器替换 KL 归约，评估仅重新平衡损失分配是否可生效。完整 TurnOPD 整合两个预算控制器。我们报告完整训练下的整体 Avg@4，取最后四个评估检查点的平均。

**结果。** 图展示了整个训练的完整验证曲线，而表总结了 100 优化步后的 Same-Step Avg@4 准确率和累计时钟时间。结果支持预期的分工。仅自适应深度将 100 步时钟时间从 4.42h 削减到 1.96h，但准确率从 83.0 略微降到 82.8。这表明减少 rollout 深度本身不是完整的训练解：它节省计算，但不修复第 4.4 节指出的损失分配问题。相反，线性 KL 混合将准确率提升到 85.1，表明损失分配器直接改进了优化，但它仍花费 2.59h。完整 TurnOPD 结合两种效应：它取得最佳平均准确率（86.3）同时匹配自适应深度运行的低时钟时间（1.93h）。值得注意的是，自适应 rollout 深度配合回合级 KL 归一化单独有时可产生接近或略高于 TurnOPD 的最终表现。然而，TurnOPD 在训练中期阶段优于这些替代，显示出更快的进度和更好的中间结果。因此，消融讲述了一个连贯的故事：rollout 深度预算控制器提供效率杠杆，渐进式损失预算控制器提供优化杠杆，二者结合给出最佳准确率—时间权衡。

### 7.2 KL 归一化的效果
**动机与实验设置。** 第 4.4 节指出 KL 损失归一化存在预算分配问题：标准（轨迹级）方法大多聚焦浅层回合，而硬的回合级策略可能过度补偿，将过多权重放在罕见支持的深层回合。为更好理解，我们比较三种 KL 归一化方案：轨迹级 KL、硬回合级 KL 和我们的线性混合方法。为公平，我们报告每种方法的 Same-Step Avg@4 以及花费在有效回合最深第三个上的实际损失预算。

**结果。** 如表所示，轨迹级 KL 稳定但强烈偏向浅层回合：最深第三个在早期/中期/后期训练只获得 3.2/0.7/1.2% 的预算。硬回合级 KL 急剧反转这一点，瞬间给深层回合约三分之一预算，但做出突变并可能早期过度加权不可靠估计。我们的线性混合提供更平滑的过渡：α 从早期的 0.17 升到后期的 0.83，而深层回合预算从 12.8% 增加到 27.7%。该方法平衡了稳定性和定向分配，产生了最佳的 Same-Step Avg@4，尽管相对硬回合级 KL 的优势很小。

### 7.3 自适应深度覆盖敏感性
自适应 rollout 深度模块暴露两个主要超参数：(1) 覆盖分位数 p，以及 (2) 完成累积分布函数（CDF）是仅从成功轨迹计算还是从完整轨迹总体计算。实践中，许多开放式智能体任务不提供成功与失败轨迹的可靠区分。此外，OPD 算法本身并不根本依赖表示任务成功的奖励信号。为评估更一般设定下的鲁棒性，我们进行了额外实验，在无成功条件 CDF 的情况下评估自适应深度控制器。

对于这个超参数研究，我们扫描 p∈{0.4, 0.6, 0.8} 在成功条件和完整总体 CDF 上的两种设定。图总结了四个诊断指标：成功条件和完整总体 CDF 设定下的验证准确率和 EMA 平滑 rollout 视野（ema-H）。这里 ema-H 指指数平滑平均 rollout 深度，直接决定有效的学生 rollout 视野。我们总结主要观察如下：

(1) 分位数参数 p 直接控制目标 rollout 视野。增大 p 带来略高的终成功率和更深的 rollout 视野及相应增加的训练时间。例如，在完整总体 CDF 下，设 p=0.6 在 1.66 小时达到 85.1 的准确率，而 p=0.8 将准确率提升到 85.8 但将所需时间增加到 1.83 小时。

(2) CDF 来源显著影响效率。完整总体 CDF 更激进：它一致性地增加 ema-H 和时钟时间，相比成功条件 CDF。这符合直觉，因为完整总体 CDF 纳入了许多失败轨迹，包括那些因重复或无产出工具使用而停滞在最大 rollout 深度的轨迹，从而高估了所需深度。尽管如此，如图中所示，完整总体 CDF 仍然有效，但需要适当更低的 p 值以匹配成功条件 CDF 的效率和表现。

## 8. 结论
我们研究了面向长程语言智能体任务的在线策略蒸馏。我们的诊断显示原始 OPD 遭受两个分配错配：全视野 rollout 可能在低产出的尾部回合上花费计算，而轨迹级 KL 归约可能将损失集中在浅层 token 上。TurnOPD 用回合级预算应对这些错配：它自适应 rollout 深度，并渐进式地将 KL 归一化转向回合均衡的监督。在 ALFWorld、WebShop 和 Multi-Hop Search 上，TurnOPD 将准确率—时间前沿推进到原始 OPD 之外。

总体而言，我们的结果暗示了对智能体 OPD 更宽泛的教训。长程智能体中监督的单位不应被视为扁平的 token 位置，而应被视为演化中交互轨迹内的回合条件决策。TurnOPD 为长程语言智能体的回合感知、预算自适应训练开辟了一条路径。
