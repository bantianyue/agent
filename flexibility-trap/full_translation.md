# The Flexibility Trap: Rethinking the Value of Arbitrary Order in Diffusion Language Models — 逐句中文翻译

## 摘要（Abstract）

扩散大语言模型（dLLMs）打破了传统 LLM 严格的从左到右约束，使得 token 能以任意顺序生成。直观上，这种灵活性意味着一个严格超集自回归固定轨迹的解空间，理论上能解锁更优越的推理潜力。然而，在本文中我们发现，对通用推理任务（如数学和代码）而言，任意顺序生成实际上可能限制 dLLMs 的推理潜力。我们观察到，dLLMs 倾向于利用这种顺序灵活性绕过对探索至关重要的高不确定性 token，这会导致解覆盖范围过早塌缩。这一观察促使我们重新思考 dLLMs 的强化学习方法——当前大量复杂度（如处理组合爆炸的轨迹和难以处理的对数似然）都致力于保留这种灵活性。我们证明，简单地放弃任意顺序、直接应用标准的 Group Relative Policy Optimization（GRPO）就能有效激发推理能力。我们的方法 JustGRPO 极简却出奇地有效（例如 GSM8K 上 89.1% 的准确率），同时完整保留了 dLLMs 的并行解码能力。

## 1 引言

近期研究发现扩散大语言模型（dLLMs）快速增长，它们将序列生成视为离散去噪过程，挑战了主流的自回归（AR）范式。dLLMs 吸引力的核心在于其理论上的灵活性，这提供了两个相对于严格从左到右因果链的独特优势：高效的并行解码和任意顺序生成能力。

虽然并行解码的效率优势已被充分证明，但任意顺序生成的含义仍相对未被探索。理论上，无约束的生成顺序构成固定自回归轨迹的超集，有潜力解锁更高级的问题解决能力。同时，一些工作已展示了非顺序生成在特定任务（如数独和斑马谜题）上的优越性。受这些成功和理论前景的驱动，研究社区越来越多地采用强化学习（RL）来为通用推理任务（如数学和代码）激发类似的先进能力。

在本工作中，我们提出了一个反直觉的观察：对这些通用推理任务而言，任意顺序生成实际上可能缩小而非扩大 RL 所能激发的推理潜力。为了严格评估这一点，我们采用 Pass@k 指标，该指标衡量解空间的覆盖范围。近期研究表明，RL 主要作用是对基模型的分布进行锐化；因此，基模型的 Pass@k 性能可以作为 RL 训练后模型可达推理上限的有效代理。在该指标下，我们比较了任意顺序生成与标准 AR 解码在 LLaDA-Instruct 上的推理潜力。如图 1（左）所示，将 dLLM 限制为标准 AR 顺序往往能产生更高的 Pass@k，从而带来比其灵活对应模式更高的推理边界。

这种反直觉的观察与不同顺序如何处理不确定性密切相关。

推理本质上是非均匀的：它依赖于稀疏的"分叉 token"，通常是连接词如"Therefore"或"Since"，这些 token 不仅仅是延续一个句子，而是将逻辑轨迹引导到不同的分支。在这些分叉点，推理路径发生分歧，自然地表现为熵的局部尖峰。标准 AR 解码强迫模型直面这种不确定性（图 2a）。通过在这些分叉点精确采样，模型能够探索不同的推理路径，从而保留生成推理过程的多样性。然而，任意顺序生成允许模型绕过这些困难决策（图 2b）。这种灵活性通常被用于优先处理低不确定性 token，这实际上将推理路径锚定在较容易的部分上，然后才决定通向这些部分的连接词。当模型最终回到填充跳过的分叉点时，已经建立的未来上下文过早地消除了它们的歧义。我们将这种现象称为熵退化：分叉点原本固有的高熵被抑制了。模型不再是在分支点导航，而是在对齐连接词以桥接一个预先确定的缺口。

上述观察促使我们重新思考这些通用推理任务中 dLLMs 的 RL。当前方法建立在"保留任意顺序灵活性至关重要"的假设上。这一承诺带来了沉重的代价：算法必须应对去噪轨迹的组合爆炸和难以处理的边缘似然，迫使依赖于不精确的近似。然而，如果任意顺序对目标任务的潜力激发并非必要、甚至有害，那么这种复杂性可能是不必要的。

为此，我们提出回归简洁——JustGRPO。我们证明，激发通用推理任务的推理潜力不一定需要复杂的、扩散特定的 RL 适配。相反，只需在 RL 训练期间将 dLLM 视为 AR 策略即可有效实现。这允许我们在不做修改的情况下应用标准 GRPO，将一个原本难以处理的优化问题转化为一个定义良好的任务。关键的是，这种 AR 公式仅在 RL 训练期间作为更好的探索的"脚手架"使用。dLLM 的原生架构保持不变——例如不施加因果掩码——从而保留其双向注意力和离散扩散公式。最终，推理能力的激发（受益于顺序探索）与推理执行的推理（受益于 dLLMs 的并行解码）被解耦。

尽管其简洁，JustGRPO 非常有效。它在 GSM8K 上达到 89.1% 准确率，在 MATH-500 上达到 45.1%，与依赖复杂扩散特定 RL 适配的方法相比毫不逊色（表 3）。更重要的是，如图 8 所示，AR 训练的模型完全兼容并行解码，表明通过 AR 探索获得的推理能力不需要牺牲 dLLMs 标志性的推理效率。

## 2 预备知识

### 2.1 扩散大语言模型

扩散大语言模型（dLLMs），特别是掩码扩散模型（MDMs），通过迭代去噪一个从完全掩码 token 初始化的掩码状态 x_t 来生成序列。该过程由连续时间变量 t∈[0,1] 索引，表示掩码比例。给定一个干净序列 x_0，前向过程以概率 t 独立地掩码每个 token。在每一步，模型对掩码位置进行预测，然后根据置信度选择一部分 token 揭露——低置信度的 token 保持掩码状态以待后续迭代。

### 2.2 带有可验证奖励的强化学习

带有可验证奖励的强化学习（RLVR）已成为增强 LLM 推理能力的主要范式。基于群体的方法，如 GRPO，从旧策略中采样一组输出，并优化一个替代目标，该目标结合了基于优势的 token 级策略梯度项和相对于参考模型的 KL 散度正则化项。对于 dLLMs，token 级重要性比率 ρ_{i,k} 定义为当前策略与旧策略在给定历史条件下生成第 k 个 token 的概率之比。由于 dLLMs 不像 AR 模型那样具有唯一对齐的条件概率，这些比率的定义本身就有歧义，这构成了扩散特定 RL 适配的核心困难。

### 2.3 Pass@k 作为推理潜力的代理指标

为了严格量化 dLLMs 的推理能力边界，我们采用 Pass@k 指标。在 RLVR 的背景下——目前增强推理能力的主导范式——探索是改进的前提。RL Agent 只有能够在探索阶段采样到正确的推理路径以获得正奖励信号，才能强化该路径。

因此，Pass@k 被广泛确立为模型推理潜力的标准度量。它衡量在 k 次独立采样中至少生成一个正确解的概率，实际上代表了 RL 优化可达解空间的上界。形式上，给定 n 个样本其中 c 个正确，Pass@k 的计算公式为公式（4）。

## 3 灵活性陷阱

在本节中，我们实证检验了任意顺序生成的灵活性是否转化为更高的推理潜力。我们比较两种解码模式：任意顺序（遵循标准扩散解码与低置信度重新掩码）和 AR 顺序（禁用任意顺序灵活性，生成严格限制为从左到右解码）。我们采用先前扩散 LLM 工作中常用的实验设置：最大 256 token，在 256 步中解码，半自回归块大小 32。采样温度设为 0.6。提示模板遵循 Zhao et al.（2025）。

### 3.1 任意顺序可能限制推理潜力

**Pass@k 分析。** 我们首先使用 Pass@k 指标在三个代表性 dLLM 上评估推理潜力：LLaDA-Instruct、Dream-Instruct 和 LLaDA 1.5，在四个推理基准上：GSM8K、MATH-500、HumanEval 和 MBPP。如图 3 所示，虽然任意顺序在 k=1 时通常达到有竞争力的性能且在许多情况下更好，但其扩展曲线明显比 AR 模式平缓。随着 k 增大，AR 模式展现出更强的发现更多正确解的能力。

**解空间覆盖。** 人们可能会想，任意顺序是否探索了一个不同的解空间（尽管效率较低），这可以解释其较低的推理潜力。我们通过分析 k=1024 时 LLaDA-Instruct 的解覆盖来检验这一点。如图 4 所示，我们发现通过任意顺序生成的解大多与 AR 解码发现的解重叠，且实际上形成一个更小的子集。例如，在 HumanEval 上，21.3% 的问题仅能被 AR 解决，而相反的情况很少见（0.6%）。虽然任意顺序生成理论上意味着更大的解空间，但在实际采样方案下能有效达到的解集似乎更受限。

**更多任意性，更少潜力。** 到目前为止我们对比了任意顺序和 AR 顺序作为两个极端，但任意性的程度不是二元的。dLLMs 中的半自回归协议通过块大小 B 控制它：序列被分割为大小为 B 的块，在每个块内模型自适应选择要揭露的 token。因此 B 设置了模型可以自由选择下一个位置的范围，B=1 表示没有自由度（纯 AR 顺序），更大的 B 允许更任意的解码。我们现在扫描 B 来检验任意性程度如何影响推理潜力。

如图 5 所示，趋势是一致且单调的：在所有 k∈{8,32,128} 上，Pass@k 随着 B 增大而下降。这表明该效果是一致的而非固定在两个极端设置上：在此设定下，更少的任意性与更高的推理潜力一致相关联。

### 3.2 机制：熵退化

**自适应解码绕过逻辑分叉点。** 为了理解为何理论上更大的 dLLM 解空间在实践中似乎塌缩，我们更仔细地检查两种解码模式的行为。在 AR 顺序中，模型被约束为严格解析每一步最左侧的未知 token，迫使模型直面不确定性。相比之下，任意顺序基于模型置信度自适应选择 token 更新，优先生成"容易"的高确定性 token 而绕过"困难"的 token。检查频繁被跳过的 token 揭示了一个清晰的模式：扩散采样器不成比例地推迟逻辑连接词和过渡标记，如"Therefore"、"Thus"和"Since"。先前工作已表明这类 token 通常具有高熵（在 dLLMs 中也是如此，见图 7），并充当"推理火花"或"逻辑分叉点"，作为决定后续推理方向的分支点。在传统语言模型中，保持这些 token 的高熵状态对有效探索推理空间至关重要。

**"熵退化"现象。** 任意顺序的自适应行为如何影响这些逻辑分叉 token？我们测量了它们在解码时的熵（图 7，更多结果见附录 C）。在 AR 顺序中，这些 token 在解码时通常保持高熵，指示一个相对丰富的分支点，其中多条推理路径仍然可行。相比之下，任意顺序表现出熵的急剧下降。通过推迟逻辑连接词，模型优先在决定通向这些连接词的逻辑之前生成较容易的未来 token。当模型最终回到填充跳过的连接词时，未来上下文的存在显著降低了不确定性。结果，模型不再是做一个开放式的导航决策，而更像是回顾性的对齐以弥补一个预先确定的结论。我们将此现象称为熵退化。

**结论。** 总结而言，我们的发现表明，在通用推理任务中，任意顺序的灵活性可能无意中有利于推理时的利用而非探索。观察到的熵退化作为这一倾向的量化指标：通过优先处理低不确定性决策，模型隐含地在生成过程早期将其轨迹锚定到特定结果。这有效地约束了解空间，可能产生更高的单次一致性，但限制了复杂问题解决所需的广泛探索。标准的 AR 排序通过严格遵守因果链，保留了逻辑分叉点的高熵特性。这种无法绕过关键决策点的特性鼓励模型从不同的推理分支中采样，从而有助于保留强化学习所需的解覆盖。

## 4 "Just GRPO" for dLLMs

第 3 节的发现表明任意顺序可能限制 RL 可及的推理潜力。尽管如此，当前 dLLMs 的 RL 方法仍沉重地背负着保留这种特定灵活性的负担。在本节中，我们考察这种灵活性施加的"代价"（第 4.1 节），并说明放弃它如何实现一个极简而有效的解决方案：JustGRPO（第 4.2 节）。

### 4.1 dLLMs RL 中的灵活性代价

现有的扩散 RL 方法建立在一个前提下：策略必须适应去噪轨迹的组合空间以保留任意顺序生成。这一设计选择虽然概念上通用，但引入了若干挑战：

**Token 级分解的歧义性。** 在 dLLMs 中，生成状态 s_t 是一个依赖于随机揭露轨迹 τ 的噪声序列。与自回归模型不同，dLLMs 不允许唯一、索引对齐的条件概率形式 π(o_t|s_t)，使得 token 级信用分配变得模糊，导致标准重要性比率 ρ_t 难以定义。

**难以处理的序列似然。** 自回归模型将序列似然分解为所有步骤的条件概率乘积，而 dLLMs 需要对所有有效去噪轨迹进行边缘化，即 π_θ(o|q)=∑_{τ∈𝒯} π_θ(o,τ|q)。对于长度为 N 的序列，轨迹空间的大小为 O(N!)，使得精确似然计算不可行，迫使现有方法依赖于 ELBO 基的替代目标而非原始目标。

**采样器-学习器不匹配。** 即使有精确的似然近似，一个更微妙的问题仍然存在。实践中，rollout 样本通常由基于置信度的生成 o~π_θ^conf(o|q) 产生来导航组合空间。然而，ELBO 目标仍针对原始模型分布 π_θ(o|q) 的似然，而非实际采样策略 π_θ^conf(o|q) 的似然，导致 rollout 与优化之间的不匹配，这可能会降低性能。

### 4.2 JustGRPO

我们提议回归简洁。由于纯自回归顺序在我们的分析（第 3 节）中展现了更高的推理潜力，我们在 RL 阶段明确放弃任意顺序生成。这一约束将 dLLM 从一个混乱的序列去噪器转化为一个定义良好的自回归策略。

**公式化。** 标准 GRPO 假设一个策略 π(o_k|o_{<k},q) 接受一个所有 token 都已观测到的部分序列 o_{<k} 并一次预测一个 token o_k。然而，扩散语言模型被架构为序列级去噪器，接受一个包含混合的观测 token 和掩码 token 的完整序列，并同时预测所有掩码位置的原始值。

通过放弃任意顺序生成，我们能够弥合上述差距并严格定义 dLLMs 的 AR 策略 π_θ^AR。为了获得给定历史 o_{<k} 时下一个 token o_k 的概率，我们构造 x̃_k 其中过去被观测、未来被掩码。

虽然扩散语言模型对所有掩码位置输出预测，但自回归策略只关心下一个 token o_k。我们将 π_θ^AR 定义为在掩码序列上模型在第 k 个位置 logits 的 Softmax。

这一公式使得标准 GRPO 能够直接应用于扩散语言模型。对于每个查询 q，我们使用旧策略采样一组输出 {o_i}。GRPO 目标包含 token 级概率比率的裁剪替代项和 KL 散度正则项。

**备注。** 人们可能会担心在 AR 模式下训练是否从根本上将扩散模型转变为标准自回归模型。事实并非如此。AR 约束仅应用于 RL 训练期间以实现更有效的探索和信用分配。关键的是，这优化了模型分布而不施加结构约束（如因果掩码），后者可能会改变底层结构或损害 dLLMs 原生的并行采样能力。实证上，模型仍然与并行采样器兼容以在推理时加速解码。JustGRPO 因此受益于基于 AR 的推理探索，同时保留了 dLLMs 的并行能力（见第 5.2 节）。

## 5 实验

我们在标准数学推理和编程基准上评估 JustGRPO。实验设计旨在检验两个假设：（i）在 RL 训练中强制 AR 顺序可以有效激发推理能力，无需依赖复杂的任意顺序近似；（ii）这一约束仅适用于优化目标，不影响推理时扩散模型的并行解码能力。

**实验设置。** 我们在 LLaDA-Instruct 上应用 JustGRPO，并在四个标准推理和编程基准上评估其有效性：GSM8K、MATH-500、HumanEval 和 MBPP。对于数学任务，我们在每个数据集的官方训练集上训练。对于编程任务，我们在 AceCoder-87K 的子集上训练。我们直接对模型应用 JustGRPO，无额外任务特定 SFT，使用全参数微调。训练配方主要遵循 Huang et al.（2025b）。评估时遵循标准 LLaDA 评估协议，使用低置信度重新掩码配合半自回归解码，块大小为 32（每步揭露 1 个 token），采样温度为 0。

**推理任务上的性能。** 表 3 报告了系统级比较。我们观察到，简单地应用标准 GRPO 公式——尽管无需扩散特定 RL 适配——已经达到了强大的总体性能。在 GSM8K 上，JustGRPO 达到 89.1% 准确率（序列长度 256），与先前扩散特定方法相比具有竞争力或更高，在更具挑战性的 MATH-500 上也有类似趋势。它总体上与 LLaDOU 和 LLaDA 1.5 保持竞争力，后者利用了辅助可训练模块或更大规模的私有训练数据。

### 5.2 JustGRPO 保留并行解码

我们进一步考察 AR 训练是否损害 dLLMs 的并行解码能力。我们使用训练无关的熵界（EB）采样器来评估不同并行度下的推理性能。

图 8 显示我们的模型保持与并行解码的完全兼容性，并展现出与原始 LLaDA-Instruct 模型相比有利的速度-准确率权衡。有趣的是，随着并行度增加，性能增益变得更显著。虽然基线模型在高并行度时性能急剧下降，我们的模型保持相对更稳定的性能。例如，在 MBPP 上，准确率差距从保守设置（1 token/步）的 +10.6% 扩大到激进设置（~5 token/步）的 +25.5%。这表明 AR 公式可能作为有效的训练"脚手架"来优化底层模型分布，而非过拟合到特定轨迹。这种优化后的分布似乎比原始模型对并行采样中的近似更具韧性。

### 5.3 训练效率

应用精确 GRPO 到 dLLMs 带来了结构性的权衡：与自回归模型不同，dLLMs 必须独立评估每个位置而非在单次因果前向传播中完成，因此计算精确似然产生了额外的每迭代开销。然而，图 9 显示即使有这种开销，JustGRPO 在其准确率/时钟时间权衡上仍然有竞争力，在可比时间内匹配了有代表性近似基线（ESPO）的峰值准确率并继续提升。

此外，这种开销远非根本性的。其主要来源是计算 GRPO 目标中每个位置的概率比率 ρ_{i,k}。受我们关于推理由稀疏高熵分叉 token 引导的发现启发，我们引入 JustGRPO-Fast，仅在顶部 25% 最高熵的位置评估 ρ_{i,k}，消除了 75% 的这些前向评估。

重要的是，由于每个 token 的熵可以在 rollout 阶段直接记录，识别高熵位置的额外开销几乎可以忽略。实证上，JustGRPO-Fast 改善了准确率/时间权衡，在更少的时间内达到与 ESPO 相当的准确率。

## 6 相关工作

**扩散语言模型。** 受扩散模型在连续域中成功的启发，近期工作将扩散扩展到离散文本生成。早期的嵌入空间方法面临优化和离散化挑战，导致了掩码扩散模型的采用——直接在离散 token 空间通过随机掩码操作。近期如 LLaDA 和 Dream 等大规模模型取得了与 AR 模型竞争的性能。在文献中讨论的 dLLMs 各种优势中，两个方面受到特别关注。首先，dLLMs 天然支持并行解码，实现显著的推理加速。其次，其非自回归公式允许任意顺序 token 生成，这被假设为通过放宽严格的从左到右约束来有益于复杂推理。

**顺序任意性的价值。** 虽然早期研究在受约束的任务中验证了任意顺序生成，但近期研究将其扩展到通用推理。一些工作表明 dLLMs 可自然地表现出非标准解码行为（如先写草稿），而另一些则明确优化解码调度以提升性能。此外，一些研究也使用 Pass@k 来衡量 dLLMs 的推理潜力。认识到这一潜力，这些工作主要聚焦在任意顺序范式内提升性能，而较少考察这种益处是否唯一地与顺序任意性挂钩。近期，Du et al.（2025）质疑了任意顺序的必要性，认为强制模型学习均匀排列会导致对底层数据分布的显著更宽松的近似。虽然他们的分析聚焦于预训练，我们在推理和 RL 中观察到类似的失败模式，表明灵活性可能会退化 RL 训练所必需的探索。这也与更广泛的视角相关——序列的顺序承载了超出其内容的宝贵结构性信息，而任意顺序生成往往忽略了这一点。

**扩散语言模型的强化学习。** dLLMs 的 RL 面临与自回归范式不同的结构性优化障碍，主要源于去噪轨迹的组合爆炸。虽然早期的尝试试图直接适配 token 级公式，但它们通常受限于状态转移定义不明确，迫使依赖平均场近似。因此，该领域已转向序列级视角，采用各种替代目标来近似难以处理的边缘似然。然而，跨这些方法往往存在离策略不匹配：探索所需的不确定性引导采样与底层扩散先验的差距，这可能在缺乏原则性校正时使梯度偏置。两个值得注意的例外部分解决了这些问题。LLaDOU 引入一个辅助策略来建模 token 位置选择，实现了直接的轨迹似然估计；TraceRL 通过基于缩放的逐步 MDP 将优化与推理轨迹对齐。尽管如此，两者都保留了完整的任意顺序机制，隐含地假设了其必要性，而我们质疑的是：通过重新考虑任意顺序本身的必要性，是否可以更简单地实现有效的 RL 训练。

## 7 结论

扩散语言模型的直观吸引力在于其顺序任意性，常被看作一种在复杂推理路径中导航的有前景的机制。然而，我们的研究表明，对通用推理任务（如数学和代码）而言，这种无限制的灵活性可能无意中约束了推理潜力。具体来说，任意顺序生成似乎优先考虑单条轨迹的精炼而非更广泛的解覆盖。

这一观察指向一个更简单的激发 dLLMs 推理能力的方案。通过使用标准自回归目标来对齐模型，我们使 GRPO 无需针对顺序任意性的复杂适配即可直接应用。这个方法，JustGRPO，表明在训练期间有意约束探索顺序——尽管其简洁——可以在推理性能上产生显著提升，同时完全保留 dLLMs 在推理时的并行解码能力。通过回归基础的从左到右顺序来进行对齐，本文邀请学界重新思考扩散语言模型开发中任意顺序与 AR 顺序之间的权衡。
