# 1 引言

大型语言模型架构已经快速发展（Liu et al., 2024; Yang et al., 2025; Grattafiori et al., 2024; Liu et al., 2025a; Team et al., 2025; Yang et al., 2026），这得益于改进的注意力机制（Vaswani et al., 2017; Yuan et al., 2025; Shazeer, 2019; Ainslie et al., 2023）、混合专家（Mixture-of-Experts，Dai et al., 2024; Jiang et al., 2024），以及在宽度、深度和数据量上的扩展（Kaplan et al., 2020; Hoffmann et al., 2022）。然而，承载 token 表示跨层传递的残差流（residual stream）基本没有变化：它仍然作为单一恒等路径运行，对跨层信息流没有提供可学习的控制（He et al., 2016）。超连接（Hyper-Connections，HC）（Zhu et al., 2024）挑战了这一设计，它用 N 条并行残差流替换单一残差流，并由可学习的混合矩阵控制。在 HC 基础上，流形约束超连接（Manifold-Constrained HC，mHC）（Xie et al., 2025）使多流残差训练在大规模下保持稳定，是目前最先进的变体。残差流扩展以适度的额外 FLOPs 增加了模型的持久状态（persistent state），提供了一种超越宽度和深度的记忆扩展形式。先前结果（Zhu et al., 2024）在从 N=1 扩展到 N=4 时观察到的显著提升表明，这是一个有前景的扩展维度。然而，现有的 HC 家族方法（Zhu et al., 2024; Xie et al., 2025; Yang and Gao, 2026; Liu et al., 2026）通常止步于 N=4。我们通过目前大规模下最先进的 HC 表述 mHC 来研究这一问题。图 1 的实验表明，朴素地进一步增大 N 会带来收益的快速递减：从 N=4 到 N=16，loss 仅边际性改善，而训练 FLOPs 增加了 32%，使得这一扩展维度在很大程度上未被实现。

我们认为这种收益-成本失衡并非偶然，而是源于两个截然不同的瓶颈：一个限制了更大 N 的收益，另一个增加了其成本。第一个是信息瓶颈：每条流本应存储层输出的不同加权历史，但每一层只向多流状态注入单一回写（write-back）信号。随着 N 增长，形成有意义且多样的流历史需要比这一单一信号更丰富的回写信息，使得额外的流越来越冗余。第二个是计算瓶颈：在 mHC 中，主导成本来自通过输入依赖的投影生成残差映射 ℋ_res ∈ ℝ^{N×N}。由于该投影要从 N·C 维的残差状态预测 N² 个系数，其成本随 O(N³C) 缩放，使得扩展成本的增长远快于其性能收益。这两个瓶颈共同解释了为什么简单地增加流数并不能按比例转化为更多有用的容量。它们也澄清了要使扩展率成为一个真正的扩展维度需要什么：模型必须提供更多样的回写信息，同时避免扩展 ℋ_res 的立方级成本。

因此，我们提出 xHC（Expanded Hyper-Connections，扩展超连接），这是第一个在 N=4 之外实现 HC 家族模型有意义扩展的方法。基于 mHC 稳定的多流表述，xHC 通过两个互补的设计使大 N 扩展既有效又经济。为了增加更大 N 的收益，xHC 沿因果 token 序列引入时序特征增强（temporal feature augmentation）：它利用来自邻近 token 的低成本特征来丰富回写信号，使用多尺度因果卷积（multi-scale causal convolutions）随着流数增多提供更多样的信息。为了控制更大 N 的成本，xHC 引入稀疏残差流架构，只为 N 条流中的 k 条激活流进行残差混合和回写，同时保持读路径稠密，使每一层仍能访问完整的 N 流状态。这两个设计在结构上解耦却高度协同：随着 N 增长，时序增强变得更加有用，因为额外的流需要更丰富的回写信息；而稀疏残差更新变得更加有价值，因为它们显著减少了大 N 扩展引入的额外 FLOPs。

在经验上，xHC 相比 mHC 和原始残差基线都带来了显著提升。如图 2 所示，在 18B MoE 规模下，xHC 持续改善了预训练 loss 和下游性能。它达到了比 mHC 和原始基线更低的终训练 loss（1.758 vs. 1.776 vs. 1.799），并将平均下游分数从 mHC 的 44.8 提升到 48.8，同时相比原始基线仅增加 4.1% 的训练 FLOPs。当骨干网络使用 Muon 训练时，xHC 仍然有效，表明其收益并非特定于 AdamW。

更重要的是，xHC 改变了扩展率本身扩展的收益-成本权衡。如图 1 所示，在 2.5B MoE 模型上，mHC 中将 N 从 4 增至 16 仅降低 0.006 的 loss，却增加 32% 的训练 FLOPs。相比之下，xHC 中将 N 从 4 增至 16 降低 0.012 的 loss，仅需 4% 的额外 FLOPs。这表明 xHC 使更大的 N 显著更具成本效益，将残差流扩展变成了一个实用的扩展维度。

这种改善的收益-成本权衡也转化为跨模型规模更好的计算效率。我们在图 4 中的缩放定律实验表明，为达到相同的 loss，原始残差需要 xHC 的 1.50× 计算量，mHC 需要 xHC 的 1.19× 计算量。这证实了改进是系统性的，而非局限于特定模型规模。

总之，这些结果确立了 xHC 同时改善了残差流扩展的效用和 FLOPs 效率。然而，实用的 N 扩展训练还需要控制扩展残差状态引入的内存流量（memory traffic）。因此我们引入 xHC-Flash，它在子层之间共享路由和稠密读计算，以避免重复的全状态访问。它将每个子层的估计流量从 73.5C 降低到 40C，与 mHC 在 N=4 时所需的 34C 相当，同时保留了完整 xHC 几乎所有的性能收益。我们进一步开发了融合（fused）实现，整合残差流操作，减少内存流量和 kernel 启动开销。我们的贡献如下：

1) 瓶颈诊断。我们识别出 mHC 中更大 N 收益递减背后的两个瓶颈：受限的回写信息供给，以及稠密残差混合的立方级成本。

2) 扩展超连接。我们提出了第一个在 N=4 之外实现有意义扩展的 HC 家族方法，通过两个协调的设计：用于更丰富回写的时序特征增强，以及用于经济残差混合的稀疏残差更新。

3) 大规模验证。我们在 18B 和 28B MoE 模型上验证 xHC，并观察到两个规模下都强劲且一致的下游改进。缩放定律和 N 扫描进一步展示了系统性的计算和扩展效率，而使用 Muon 的实验证实 xHC 在 AdamW 之外仍然有效。

4) 高效部署。我们引入 xHC-Flash 和融合 kernel 实现，以减少大 N 残差流扩展中的内存流量和 kernel 启动开销。xHC-Flash（N=16, k=4）达到的每个子层内存流量与 mHC 在 N=4 时相当（40C vs. 34C），同时保留了完整 xHC 的大部分性能收益。

# 2 相关工作

跨层信息流。残差连接（He et al., 2016）是 Transformer 语言模型（Vaswani et al., 2017）中承载 token 表示跨层的默认机制。大多数 LLM 架构（Liu et al., 2025a; Grattafiori et al., 2024; Yang et al., 2025）将这一残差状态保持为单一流，同时通过门控、可学习缩放或深度相关重缩放（Srivastava et al., 2015; Touvron et al., 2021; Bachlechner et al., 2021; Wang et al., 2024a）来改善其优化或加权。其他方法改善了跨层访问或特征复用（Huang et al., 2017; Pagliardini et al., 2024; Team et al., 2026; Zhu et al., 2026），但它们是在先前的激活上操作，而非扩展持久的残差状态。与我们的工作最接近的是，超连接（HC）（Zhu et al., 2024）将残差流扩展为 N 条可学习流，而流形约束 HC（mHC）（Xie et al., 2025）通过 Sinkhorn 归一化的残差混合在大规模下稳定了这一表述，在 HC 家族方法中取得了最强性能。其他 HC 变体（Yang and Gao, 2026; Liu et al., 2026）改善了表达能力或内存效率，但现有的 HC 家族方法主要在 N=4 上运行，留下了残差流扩展能否成为 LLM 预训练真正扩展维度的问题。xHC 通过使更大 N 的扩展既有意义又经济，弥补了这一空白。

语言模型中的稀疏计算。稀疏性被广泛用于高效地扩展语言模型。混合专家（MoE）在计算上应用稀疏性：每个 token 被路由到专家子集，将总参数与每 token FLOPs 解耦（Shazeer et al., 2017; Lepikhin et al., 2020; Dai et al., 2024; Liu et al., 2025a; Team et al., 2025）。稀疏注意力则改为在 token 上稀疏化，限制每个查询只关注序列子集，减少长上下文注意力成本（Child et al., 2019; Beltagy et al., 2020; Yuan et al., 2025; Liu et al., 2025a）。xHC 在不同的维度上应用稀疏性：残差流。它只为 N 条流中的 k 条激活流进行残差混合和回写。这将主导的残差混合成本从随所有 N 条流缩放降低到只随 k 条激活流缩放，使大 N 残差记忆扩展变得经济。

## 3.2 为什么在 mHC 中扩展 N 会饱和

理解这种饱和对于将残差流扩展从小的 N 改进转变为实用的扩展维度至关重要。先前的结果（Zhu et al., 2024）表明，早期的残差流扩展非常有效：将 N 从 1 增至 4 在不到 2% 的 FLOPs 成本下带来了显著收益。这表明扩展 N 可以通过增加残差记忆来改善模型性能，提供了一个与宽度和深度正交的维度。然而，现有的 HC 家族方法（Zhu et al., 2024; Yang and Gao, 2026; Liu et al., 2026; Xie et al., 2025）通常止步于 N=4，留下了这一维度在更大 N 下是否仍有意义的问题。为了回答这个问题，我们在匹配的训练配方下扫描 mHC 中的 N ∈ {2,4,8,16,32}。如图 1 所示，超出 N=4 的扩展很快遇到收益递减：将 N 从 4 增至 16 仅降低 0.006 的 loss，而训练 FLOPs 增加了 32%。这种不利的收益-成本权衡促使我们审视是什么阻止了更大的 N 转化为有用的容量。我们识别出这一饱和背后的两个瓶颈。

信息供给瓶颈。在 mHC 中，N 条流中的每条都累积历史层输出的不同加权组合。然而，在第 l 层对第 i 条流的回写形式为：

成本瓶颈。第二个瓶颈在成本侧。在 mHC 中，从 N·C 维状态生成 ℋ_l^res ∈ ℝ^{N×N} 需要预测 N² 个系数，导致 O(N³C) 的输入依赖投影成本。这使得大 N 扩展即使额外性能增益很小时也变得越来越昂贵。具体而言，如图 1 所示，在 2.5B MoE 上，N=16 的 mHC 相比其 N=4 设置仅带来有限的 loss 降低，却增加了约 32% 的额外 FLOPs。

这两个瓶颈复合：信息瓶颈限制了更大 N 的收益，而成本瓶颈提高了其价格。它们共同瓦解了扩展 N 的投资回报。

## 3.3 xHC：扩展超连接

xHC 同时解决两个瓶颈，使扩展率 N 成为一个实用的扩展维度（图 3）。它用局部上下文特征丰富了回写信号，并采用非对称稀疏残差流架构：只有 k 条激活流经历残差混合和回写，而稠密读保持每一层与所有 N 条流相连。这将主导的 ℋ_l^res 生成成本从 O(N³C) 降低到 O(k³C)，在我们的主设置中 k=4，N=16。除非另有说明，其他实现细节遵循 mHC。

### 3.3.1 丰富回写信号

时序特征增强。如 §3.2 所分析，大 N 扩展之所以饱和，是因为每层只向所有流提供单一回写分量。直接的修复方法是为每条流计算单独的输出，但这会将层 FLOPs 乘以 N。相反，xHC 通过从邻近 token 借用低成本的局部上下文信息来丰富回写基（basis）。由于自回归预测已经以周围上下文为条件，邻近的隐藏输出与当前 token 在语义上兼容，可以整合进其回写信号。我们用轻量的因果深度可分离（depthwise）一维卷积来聚合这一局部信息，这些卷积保持自回归顺序并只增加很小开销（Gulati et al., 2020; Wu et al., 2019; Gu and Dao, 2023）。

### 3.3.3 为什么需要两个设计

这两个设计解决互补的瓶颈。时序特征增强使额外的流更具信息量，但单独使用仍留下昂贵的稠密残差混合。稀疏残差更新使大 N 变得经济，但单独使用仍留下信息受限的回写信号。它们共同使大 N 扩展既有意义又经济，第 4.5 节的消融证实了任一设计单独都不能恢复 xHC 的全部收益。

# 4 实验

我们通过语言模型预训练实验在模型规模、计算预算、扩展率、消融设置和优化器选择等多个维度上评估 xHC。我们首先在 18B 和 28B MoE 模型上将 xHC 与 mHC 和原始残差基线比较，然后通过缩放定律实验研究计算效率。接着，N 扫描和消融研究考察在 xHC 下更大的扩展率是否仍然有益，以及这两个设计是否解决了大 N 瓶颈。最后，我们测试与 Muon 优化器的兼容性。

## 4.1 实验设置

训练设置。我们在语言模型预训练设置下使用混合专家（MoE）Transformer 模型进行实验。除非另有说明，我们将 xHC 和 mHC 应用于相同的 DeepSeekMoE 风格（Dai et al., 2024）Transformer 骨干。具体而言，骨干使用分组查询注意力（GQA）（Ainslie et al., 2023）和 144 个专家、top-8 路由，每个专家实现为基于 SwiGLU 的 FFN（Shazeer, 2020）。我们在两个 MoE 规模上报告主要下游结果：一个 18B 总参数、1.7B 激活参数的模型，以及一个 28B 总参数、2.7B 激活参数的模型。我们还额外使用 10B MoE 模型进行消融，使用 2.5B MoE 模型进行 N 扫描实验。除非另有说明，xHC 使用 N=16 总流，k=4 激活流。所有模型都以 8192 token 的上下文长度在覆盖英语、中文、代码、数学和推理语料的数据混合上训练。除非另有说明，所有实验都使用 AdamW（Loshchilov and Hutter, 2017）作为训练优化器。完整的超参数和训练细节在附录 A 中提供。

基线。我们主要将 xHC 与 mHC（N=4）（Xie et al., 2025）比较，mHC 的训练 FLOPs 与 xHC 相当，是大规模下最强的 HC 家族方法。我们还包括一个标准残差流 Transformer（Vaswani et al., 2017; He et al., 2016）作为原始基线。

下游评估。我们在一个覆盖 LLM 性能四个方面的基准套件上评估：语言理解和知识（MMLU（Hendrycks et al., 2020）、MMLU-Pro（Wang et al., 2024b）、MMLU-Redux（Gema et al., 2025））；推理和数学（BBH（Suzgun et al., 2023）、CommonsenseQA（Talmor et al., 2019）、ARC-Challenge（Clark et al., 2018）、GSM8K（Cobbe et al., 2021））；代码生成和理解（HumanEval（Chen et al., 2021）、LCBench（Contributors, 2023））；以及中文语言理解（CMMLU（Li et al., 2024）、CEval（Huang et al., 2023）、C3（Sun et al., 2020））。这些基准共同提供了一个紧凑而多样的视角，判断改善的残差流扩展是否在预训练后转化为更强的泛化能力。评估协议和 shot 设置在附录 A 中提供。

## 4.4 扩展扩展率

我们评估 xHC 是否将扩展率 N 转变为一个有意义的扩展维度。我们在 2.5B MoE 模型上扫描 xHC 中的 N ∈ {2,4,8,16}（附录 A 中的细节），并与匹配扩展率下的 mHC 比较。在 mHC 中，所有 N 条流都参与稠密残差混合，因此残差混合开销随 N 快速增长。在 xHC 中，增大 N 扩大了残差记忆容量，而稀疏更新成本仍由 k 控制。图 1 绘制了训练中语言建模 loss 随训练 FLOPs（随 N 增大）的变化。在 xHC 下，loss 从 N=2 到 N=16 持续下降，N 的每一次翻倍都以很小的额外 FLOPs 带来清晰改进。相比之下，mHC 表现出快速饱和：将 N 从 4 增至 16 仅降低 0.006 的 loss，却增加 32% 的训练 FLOPs。在相同的范围内，xHC 仅以 4% 的额外 FLOPs 降低 0.012 的 loss。这些结果表明 xHC 大幅改善了残差流扩展的收益-成本权衡，使更大的 N 在实用计算预算下变得有用。

## 4.5 消融研究

消融研究使用在匹配数据预算下训练的 10B MoE 模型，为隔离每个 xHC 设计选择的效果提供了一个受控设置。模型配置和训练细节在附录 A 中提供。我们报告 Pile 测试集（Gao et al., 2020）上的验证 loss。

增量构建。遵循 xHC 的动机，我们从 N=16 的 mHC 出发，逐步添加 xHC 的两个成分：时序特征增强和稀疏残差流架构。时序特征增强通过丰富回写信息针对信息瓶颈，而稀疏残差更新通过使大 N 变得经济来针对成本瓶颈。如表 2（2）–（5）所示，向 mHC 添加时序特征增强将验证 loss 从 1.998 改善到 1.984，证实了在大 N 下丰富回写信号的好处。再添加稀疏残差流架构，则保持这一验证 loss（1.983）不变，同时将 FLOPs 开销从 20.1% 降低到 3.3%，表明稀疏更新使丰富的大 N 残差状态变得经济。总之，这些结果支持了 xHC 的设计：有效的大 N 扩展需要更丰富的回写信息和受控的残差更新成本。

信息瓶颈消融。我们单独向稠密 mHC（N ∈ {4,8,16}）添加时序特征增强，默认使用三个多尺度因果卷积分支。图 5 显示，相对于 mHC 的 loss 差距随着 N 增长变得越来越负。这一趋势与我们的诊断一致：信息瓶颈在更大的扩展率下变得更加严重，此时额外的流需要更丰富的回写信息来形成非冗余的历史。

稀疏架构消融。表 2 验证了使稀疏残差更新有效的设计。稀疏写的主要风险是信息断开：在一层更新的流可能不会被下一层选中，破坏跨层传播。同时移除稠密读和固定流会暴露这一风险，将 loss 恶化到 1.997。稠密读通过让每一层访问所有 N 条流来缓解这一问题，因此任何流中的信息无论路由如何都保持可见；在存在固定流的情况下，移除稠密读使 loss 从 1.983 增加到 1.985。固定流通过提供有保障的写目标进一步稳定稀疏更新；移除它们使 loss 从 1.983 增加到 1.986。此外，激活流预算 k 控制稀疏性-质量权衡：k=2 供给不足激活流（1.991），k=8 以更高成本带来边际增益（1.982），k=4 平衡了两者。最后，Sigmoid 路由优于 Softmax（1.983 vs. 1.988），与避免可能使流持续不激活的赢者通吃路由一致。

## 4.6 与 Muon 优化器的兼容性

上述实验使用 AdamW（Loshchilov and Hutter, 2017）。我们进一步在 Muon（Jordan et al., 2024; Liu et al., 2025b）下评估 xHC，Muon 使用 Newton–Schulz 迭代来构造正交化矩阵更新，并在 Transformer 预训练中显示出强劲结果（Team et al., 2025）。这测试了 xHC 是否超越 AdamW 仍然有效。

当使用 Muon 训练时，我们做了两个实用调整。首先，我们从时序特征增强中移除 Gram–Schmidt（GS）正交化。在 AdamW 下，GS 充当稳定机制：因果卷积分支通常与原层输出高度相关，因此没有正交化时，後映射可能组合近似平行的分量，并沿同一方向放大回写信号，导致激活增长和梯度尺度尖峰。Muon 通过对骨干矩阵更新应用 Newton–Schulz 正交化来降低这种敏感性，这使得更新谱更受控。此外，GS 在前向传播中移除平行分量，并相应地沿这些方向投影出梯度分量；在 Muon 下，我们发现这一额外投影是不必要的且略有约束性。因此在用 Muon 训练 xHC 时我们移除 GS。其次，我们只将 Muon 应用于骨干注意力和 MLP 投影矩阵，同时保留 xHC 特定的路由和映射投影在 AdamW 下。这些 xHC 投影是高度不平衡的矩阵，将 N·C 或 k·C 隐藏特征映射到低维的流控制输出，如 N 路由/前映射权重、k² 残差混合 logits 和 k·K_r 後映射权重。在默认的 N=16、k=4 设置下，它们的输出维度远小于输入维度，使得它们不太适合 Muon 的矩阵正交化。所有其他 xHC 组件保持不变。

表 3 在 18B MoE 模型上报告了与表 1 相同训练配方下的结果，Muon 应用于骨干参数，AdamW 保留给 xHC 参数；优化器设置在附录 A 中提供。xHC 在基准上相比 Muon 基线保持了显著增益，表明该架构与 Muon 兼容，并在 AdamW 之外仍然有效。

# 5 实际部署

本节考察 xHC 的实际训练效率。虽然 xHC 引入了适度的额外 FLOPs，但维护多个残差流会增加内存流量，并可能影响挂钟吞吐量（wall-clock throughput）。我们首先分析其计算和内存访问开销，然后引入 xHC-Flash 以减少重复的全状态访问。值得注意的是，xHC-Flash-4sub 达到的内存流量与 mHC 在 N=4 时相当，同时保持明显的性能优势。最后，我们描述我们的基础设施设计，具体是用于减少剩余操作运行时开销的 kernel 融合策略。

## 5.1 效率分析

xHC 的 FLOPs 开销是适度的：在我们默认的 N=16、k=4 设置下，xHC 在 28B 规模增加 3.0% 的训练 FLOPs。训练 FLOPs 和参数开销的详细推导在附录 C 中提供。如先前工作（Xie et al., 2025）所指出，HC 家族方法（Zhu et al., 2024; Xie et al., 2025）运行时开销的主要来源通常是内存流量而非算术 FLOPs。维护 N 流残差状态在每子层引入额外的 I/O 用于归一化、投影和残差混合，这可能直接影响训练吞吐量。

这一差距促使了下面开发的两个优化：xHC-Flash 在架构层面减少重复的全状态访问，而我们的融合实现减少了剩余残差流操作的开销。

## 5.3 基础设施设计

xHC 的直接实现由许多小型的、主要内存受限的操作符组成，它们重复访问残差状态，物化（materialize）归一化特征和中间映射，并产生 kernel 启动开销。我们的实现针对默认的 N=16、k=4 配置，并将这些操作组织为两个阶段：映射生成和映射应用。在每个阶段内，共享相同输入的操作被融合以减少内存流量和 kernel 启动。残差状态以 bfloat16 存储，投影操作数以 bfloat16 存储，而归一化统计量、路由、映射系数和 Sinkhorn 迭代使用 float32。

端到端吞吐量。我们在 18B MoE 模型上测量挂钟训练吞吐量，不使用流水线通信重叠，以避免通信调度混杂因素。我们重新实现的 mHC（N=4）融合 kernel 相比基线增加约 15% 的训练开销。这高于 mHC（Xie et al., 2025）报告的 6.7%，但结果不能直接比较，因为先前的测量可能使用了不同的规模、并行设置或重叠调度。xHC-Flash-4sub 在 mHC 之上增加约 11% 的开销，主要来自扩展的 N=16 全状态投影、双稠密读遍历和反向残差流操作。借助流水线通信重叠（如 DualPipe（Liu et al., 2024）），有效的端到端开销可以进一步降低。

对于 2K token 的推理预填充（prefill），mHC 相比原始基线增加 11.4% 的额外开销，而 xHC-Flash-4sub 增加 12.9%。这相对于 mHC 仅对应总预填充延迟 1.3% 的增加，与我们的观察一致：xHC-Flash-4sub 额外的训练开销主要来自反向计算而非前向残差流路径。

# 6 结论

我们提出了 xHC，一种使 HC 家族模型中的残差流扩展在常见的 N=4 设置之外变得有效且经济的方法。我们表明，在 mHC 中直接扩展 N 受到两个瓶颈的限制：回写信息不足，以及残差映射生成的立方级成本。xHC 通过时序特征增强和稀疏残差流架构解决这些瓶颈，后者在只更新 k 条激活流的同时保留稠密读访问。在语言模型预训练实验中，xHC 扩展到 N=16、k=4，在 18B 和 28B MoE 模型上显著优于 mHC 和原始基线，改善了等 loss 计算效率，并在 Muon 下保持有效。xHC-Flash 和融合 kernel 进一步减少了实用大 N 训练所需的内存和实现开销。这些结果支持将扩展率作为 HC 家族模型的一个实用扩展维度。
