S# 实验评估
H3 实验设置
T 对比对象是 HySparse 与 MiMo-V2 系列使用的 Hybrid SWA，比较覆盖模型表现、预填 FLOPs 与 KV cache 存储。实验用 80B-A3B MoE 模型：49 层 Transformer，隐藏维度 2,048，采用简化版 mHC 变体。三个模型只在注意力设计上不同。
B table1
T 80B-A3B 模型在 32k 上下文长度下预训练约 500B token；轻量后训练阶段再增加约 100B token，把智能体数据引入训练混合，并把上下文长度扩展到 256k。两个阶段内三个模型共享同一数据混合与训练计划。
T 评估覆盖知识、推理、代码与长上下文任务（MMLU、C-Eval、CMMLU、BBH、GSM8K、ARC-C、HumanEval+、RULER、NoLiMa、MRCR-v2、RULER-v2、GraphWalks），长上下文似然用内部基准 AgentPPL 与 LongPPL 衡量，后者在依赖长距离上下文的选定 token 上测困惑度。
H3 整体对比
T 预训练之后，HySparse2 的通用能力与两个基线基本相当，长上下文建模明显更强：RULER 与 NoLiMa 都是最高，相对 HySparse 分别提升 5.88 与 9.49 分；Repo Code PPL 最低，为 1.1570，略优于 HySparse 的 1.1588 与 Hybrid SWA 的 1.1578。单个通用任务上互有胜负。
B table2
T 轻量后训练之后，在 256k 以内的所有评估长度上，检索与长上下文似然的四项指标都领先两个基线：相对 HySparse，MRCR-v2 与 RULER-v2 平均分分别提升 11.30 与 19.81 分，相对 Hybrid SWA 分别提升 6.44 与 18.65 分；到 256k 时 HySparse2 的 RULER-v2 达到 58.45，HySparse 为 32.61，Hybrid SWA 为 35.74。

T 开销方面，1M token 时 HySparse2 的预填 FLOPs 相对 HySparse 降低 2.92 倍、相对 Hybrid SWA 降低 5.02 倍；KV cache 只占 2.69 GB，HySparse 为 6.72 GB，Hybrid SWA 为 12.09 GB。
