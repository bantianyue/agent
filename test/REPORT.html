五、环境踩坑记录（已修复 / 已定位）

  • httpx 走代理时 brotli 解码异常 → 请求头加 Accept-Encoding: gzip, deflate 规避。
  • bs4 find(meta, name=...) 与关键字冲突 → 改用 find("meta", attrs={"name": ...})。
  • Playwright CDP 在 MSYS 下 renderer 必崩 → 根因是 Playwright 用 pipe/websocket 控制浏览器，在 git-bash(MSYS) 子进程里渲染进程初始化即崩（连 --version 都卡死）。绕过方案：直接 subprocess 调 chrome.exe --headless=new --dump-dom，arxiv/cognition/x 帖子全部成功。
  • claude.com 单独卡死（110s 超时）：stderr 报 GPU process exited unexpectedly: exit_code=-1073741819（0xC0000005 访问冲突）。claude.com 的 Next.js 应用触发 GPU/Network 子进程在 headless 下崩溃。各 GPU flag 均无效。这是 claude.com 站点 + Chromium 149 的兼容性问题。
  • --proxy-bypass-list=<-loopback> 在 bash 里 > 被当重定向 → 用变量包裹加引号 "--proxy-bypass-list=$bypass"。
  • 每个 URL 抓取其独立 subprocess（timeout=110s 硬上限），超时不阻塞其他 URL。
