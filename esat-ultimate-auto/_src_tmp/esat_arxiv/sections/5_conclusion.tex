\section{Conclusion}
We presented \textsc{ESAT}, an environment-free pipeline that synthesizes training data for API-calling agents using only API specifications. By combining coverage-aware task generation, a state-consistent LLM-based API simulator, and a trajectory-level LLM judge, \textsc{ESAT} produces high-quality, multi-step trajectories without using any functional environment. Evaluations on the challenging AppWorld and OfficeBench benchmarks demonstrate substantial performance gains across models ranging from 1.7B to 27B parameters. On AppWorld, models trained on synthetic \textsc{ESAT} data outperform the models trained on trajectories collected from the real environment. On both benchmarks, we are able to either outperform or approach the performance of GPT-4o using significantly smaller models with 4B to 8B parameters. These results establish our environment-free data synthesis pipeline as a highly effective and scalable solution for training API-calling agents.
