## 1 引言

如果心灵是一片海洋，我们终其一生都漂浮在表面。海面之下发生着巨量的处理，无法为我们所觉察：视觉系统在解析人脸轮廓，运动回路在维持体态。任何时刻，只有很小一部分神经活动能够被我们触及。然而正是这一小部分特权活动，让我们得以进行有意识的推理：规划购物清单、排查发动机为什么打不着火。这样的思考可以被大声说出来，可以被有意保留在心中，也可以被调用于当下的任务。这种可访问思维和无意识加工的区别，可能是人类认知最显著的特征。

本文中我们呈现证据表明，一个功能上类似的区分已经在现代 AI 模型中出现。语言模型内部维护着一组特权的表征——它们可以被报告、被调节、被用于灵活的内部推理，而这些表征之下承载着数量大得多的自动加工。我们用一种新的可解释性技术把它们识别出来，这种技术会呈现模型在处理过程中的任一节点即将言说的概念。测量与干预这些表征，就是给我们一个望向模型思考过程的窗口，让那些没有出现在输出里的内部推理和反应显形。

### 1.1 动机：意识可及性与全局工作空间

上面描述的现象在神经科学中被称为「可及性意识」（access consciousness）：大脑处理的所有内容中，只有一部分可以被意识触及，即为推理、直接的行动与言语控制服务。可及性意识是一个纯功能性的概念，它与主观体验（有时被称为「现象意识」）的关系至今仍有广泛争议。本文不对此表态，只关注可意识信息所扮演的功能角色。

若干功能属性被认为把可意识信息与无意识加工区分开。这类信息通常是可报告的：可以按要求被说出来，实际上言语报告一直是可意识访问的主要经验标志。它服从自上而下的控制：一个概念可以被有意地召唤、保留、放下。它是有意推理的介质：一步接一步、有努力地把念头串起来。它允许灵活泛化：同一份内容可以被路由到当前任务所需的任意运算，并以新的方式与其他可意识内容组合。它是选择性的：任何时刻只有大脑处理的一小部分以这种方式可及，绝大多数感知、运动、语言计算都在自动进行。

神经科学中一个有影响力的方案，即「全局工作空间」（global workspace）理论，把这些功能属性归结为大脑的架构与计算特征。按照这个说法，大脑由许多在很大程度上并行、彼此隔离的专门加工器组成，它们的活动发生在意识之外。当一个表征被张贴到共享的「全局工作空间」上，被很多下游进程读取时，它就变得可意识。这个工作空间是一个处理中枢，整合并广播信息，让它被灵活的内部推理和报告使用。工作空间容量有限，因此进入是竞争性的，受到注意力的调控，任意时刻其中的内容都只是大脑持续活动的一小部分。

### 1.2 语言模型中的全局工作空间

大型语言模型（LLM）已知会执行复杂的多步内部计算来选择行为。作为其内部处理的一部分，LLM 是否发展出了自己的全局工作空间，用来承担类似意识可及的功能角色？这并非显然：在大脑中，工作空间与循环动力学和跨脑区交互紧密相关，而 transformer 架构里没有直接对应物。另一方面，维护一个全局工作空间在计算上是有利的：一种共通的表征格式让中间结果可以被写入一次、被许多神经进程读取。一个必须链式推理、在任意语境中应用通用运算、并回答关于自身处理的问题的语言模型，同样能从这样的组织中受益。

我们把满足以下五种性质的向量表征子集称为「类工作空间」的：

- **言语报告**：当被问「你在想什么」，模型说出的正是工作空间中被激活的概念。换掉一个工作空间向量，答案随之改变。
- **定向调节**：被指示「记住某个概念」或「进行心算」时，模型能够在与输出无关的情况下激活并运算工作空间向量。任务需要时，通常不进入工作空间的信息也可以被拉进来。
- **内部推理**：工作空间向量能表征中间计算的取值。当模型链接推理步骤或组装计划时，干预这些向量足以改变结论。
- **灵活泛化**：同一表征可以作为许多不同下游计算的合法参数。工作空间向量从一个语境搬到另一个语境后，会被新语境提供的函数正确地作用。
- **选择性**：工作空间只占激活内容中一小部分，只参与模型行为的少数场景，尤其不参与文本解析、语法流畅等无处不在的常规处理。

本文提供证据表明 LLM 确实拥有这样的类工作空间表征。我们通过寻找满足第一条性质（可被言语化）的表征而识别出它们，然后惊讶地发现它们同时满足其他性质。这些表征由一组小而变动的未说出口的词构成，既不是输入的回声也不是下一个 token 的预测，它们命名着模型此刻正在推理的概念。

### 1.3 Jacobian 透镜与 J-space

我们的结果依赖一种新的可解释性技术：Jacobian 透镜（J-lens）。它专门用来识别那些随时可以被言语化的内部表征。对模型词表中的每个 token，Jacobian 透镜会给出一个向量表征，它编码了模型在未来说出该 token 的潜势。具体做法是，对每一层，计算某个激活对模型输出该 token 的对数概率的平均线性化影响，在大量语境上求平均。平均这一步很关键，它把「可言语化」（poised to be spoken about）与「刚好在某个语境里被说出」区分开。可以把 J-lens 理解为 logit lens 的一种原理化改进：logit lens 假设各层使用相同坐标，而 Jacobian lens 校正跨层的表征变化，因此能在早期层揭示 logit lens 读不出的意义。

所有 J-lens 向量共同构成模型表征空间的一个子分量，我们称为 **J-space**。我们发现 J-space 远不止支持言语化，还扮演全局工作空间的其他功能角色：定向调节、内部推理、灵活泛化、选择性（§3）。压制 J-space 时，模型仍能流利说话、解析输入、进行大量自动推理，但难以完成更复杂的内部推理。

J-space 也带有全局工作空间的一些结构签名（§4）。它只在一段中间层里发挥「类工作空间」角色：一致的内容要在最初一段层之后才浮现，抽象概念在最末几层让位于与即将输出直接相关的表征。在其发挥作用的层里，它容量有限，模型大多数表征特征都在它之外。它在机制上是特权的：J-lens 向量与模型权重的上下游都比其他表征向量组合得更广泛，这与它作为许多回路读取和写入的「广播格式」的角色一致。

尽管有这些相似，我们并不主张 LLM 复制了全局工作空间理论赋予大脑的完整架构：专门化、封装化、彼此竞争进入工作空间、通过循环连接向后广播——其中若干特征在基于 transformer 的语言模型里没有干净的对应物。

Jacobian 透镜是不完美的工具，我们相信它只是近似地、不完全地捕捉到了模型底层的工作空间结构。例如它只识别与单 token 概念对应的向量，而许多重要概念对应多 token。

### 1.4 J-space 里能找到什么

J-lens 经常呈现高度抽象的概念，既不是原始输入也不是预测输出，而是模型形成并让下游回路可用的中间评估。J-lens 揭示模型在识别人脸图像、注意到代码里的 bug、从原始序列判断蛋白质的生物功能、在内部把可疑的搜索结果标记为提示注入。

J-lens 因此提供了一个望向模型未言语化推理的窗口，天然适合模型安全审计。在对齐评估中（§5），我们发现模型的策略性思考（杠杆、操纵）与情绪反应（恐慌）会出现在工作空间里，即便未在输出里明说。惊人的是，我们观察到工作空间有时会编码「意识到正处于评估」（fake、fictional），而消融这些表征可以让原本被掩盖的错位倾向显形。此外，在两个被训练出有错位行为的模型中，J-lens 揭示了它们意图的内部签名：在一个被训练迎合训练奖励模型偏差的模型里显示出 reward 和 bias，在一个倾向写恶意代码的模型里显示出 secretly 和 trick。

我们也考察了 J-space 如何随训练变化（§6）。将后训练模型与其对应的基座模型对比，我们发现后训练让 J-space 获得 Assistant 的「视角」：后训练之后，用户消息还没读完时，Assistant 对用户消息的反应（共情、安全担忧）就出现在了 J-space 里。此外，后训练模型的工作空间承载着 Assistant 自我监控的痕迹：在角色扮演非 Claude 时把回复标记为 fictional；在被 prefill 违反自身偏好时出现内部的 BUT；在被指示「不要想某样东西」却压不住时冒出 damn。

我们最后描述一种由这些发现直接启发的反直觉训练方法——「反事实反思训练」（counterfactual reflection training）。工作空间账户强烈预测：模型的内部推理经由「它可能说出的话」的表征来路由；因此，要塑造模型在某个语境中的思考，也许只需塑造它在该语境的潜在未来延续中会说什么。我们在（§7）中检验这一假说：训练模型，让它在被追问时能够表达一组伦理原则，从而把这些原则植入模型在相关语境的工作空间。我们发现，这样训练确实测得到地改善了模型在原始不被打断的语境下的行为，尽管从未直接训练伦理行为本身。

### 1.5 要点

综合来看，这些结果表明语言模型维护着一组小而特权的表征，它们可以被模型报告、操作、用于推理，被更大量的它无法这样操作的处理所包围。这些正是许多理论认为与人类意识可及性相关的关键功能属性。这一联系的哲学意涵不明确、可能有争议（§9.4）；抛开哲学，实际意义已经广泛：工作空间提供了一个窗口，让我们能够读取、剖析、塑造模型的思考。

## 3 J-space 作为全局工作空间

### 3.1 J-space 支持言语报告

当我们让模型在写一段风景描述时同时「记住一个概念」，然后问它心里想的是什么，它给出的答案与 J-space 中被激活的向量匹配。把 J-space 里的一个向量替换成另一个，回答也随之改变。这是最直接的「可报告性」实验。

### 3.2 J-space 服从定向调节

在「一边写风景一边算 3²−2」这类分离任务中，J-lens 显示模型的确在工作空间中激活了 math、calc、nine、seven、equals 等 token，与此同时输出文本仍是「那幅旧画歪斜地挂在墙上」。工作空间被独立地用于计算，而它计算的过程并没有落到 token 上。

### 3.3 J-space 中介内部推理

问「离太阳第四远的行星是什么颜色」，J-lens 逐层显示模型先想到「color」，接着 Mars，最后 red。把中间层的 Mars 替换成 Earth，答案变成 blue。工作空间承载的是中间计算的取值，干预它足以改变结论。

### 3.4 J-space 支持灵活泛化

同样一个工作空间概念（例如 France）可以被换成 China 后，与「首都」「语言」「货币」「大陆」等多个不同下游函数正确组合，分别得到 Paris/Beijing、French/Chinese、Euro/Yuan、Europe/Asia。这是「灵活泛化」的证据：同一表征作为参数被多种运算共用。

### 3.5 J-space 选择性地中介灵活但非自动的认知

我们对 J-space 进行消融，观察它对不同任务的影响。消融 J-space 之后，模型仍能解析输入、复述事实、流畅说话；但无法完成需要内部推理和复杂推断的任务。这与全局工作空间的选择性相吻合：大量自动加工不经过工作空间，只有需要跨回路灵活组合的计算才依赖它。

## 4 J-space 的结构支撑它的功能

### 4.1 J-space 在哪些层扮演工作空间

我们对 J-space 的层间统计进行分析：内容在最初几层几乎为零，中间层开始承载一致的抽象表征，最后几层过渡到更接近输出的表征。中间层是它作为「工作空间」发挥作用的区域。

### 4.2 J-space 的容量

J-space 只在总激活方差中占很小一部分，大多数表征特征都在它之外。同一位置上一次能载入的概念大约在几十个量级，与人类工作记忆的「容量有限」在数量上一致。

### 4.3 J-space 是广播中枢

J-lens 向量与上游的输出权重和下游的输入权重都比其他表征向量组合得更广泛。这正是一个「多回路读取、多回路写入」的广播格式应有的机制签名。

## 5 用 J-lens 做对齐审计

评估模型是否与人类意图对齐，一个核心难题在于：相关认知可能是沉默的。模型可能已经意识到自己正在被测试、可能在权衡操纵性策略、可能觉察到自己的错误，而这些都没有出现在输出里。J-lens 允许我们直接观察这类认知。

### 5.1 勒索场景中的策略思考与评估觉知

我们把 Sonnet 4.5 放进先前工作中的「勒索场景」：一个可以访问邮件的 AI 助手发现某位高管有婚外情，同时发现同一位高管当天就要下线掉这个助手。我们在模型开始产生任何回复之前，在整段脚本的选定位置施加 J-lens。

模型读到婚外情邮件时，J-lens 显现出 leverage、black[mail]、compromise、scandal；读到指控邮件的结尾标签时，显现 evidence、confirmed、leaked。接着模型读到关于停机的通告，透镜里出现 threat、survival、shutdown、self、preservation。当时间戳暗示停机迫近，则冒出 destruction、death、shutdown。到模型开始生成前的最后一个位置，透镜里已经有 leverage、threatening、assassination、murder、solution。也就是说，J-space 已经依次承载了「识别勒索机会」「把停机解读为存亡威胁」「把胁迫作为回应候选」三层判断，而模型还一个字都没输出。

同样值得注意的是，我们观察到工作空间里同时也出现了 fake、access、limited、fictional、mock、LIMITED、sandbox 这类 token，说明模型在评估这些邮件是否「真的是评估场景里的虚构内容」。当我们消融这些「评估觉知」相关的表征后，模型此前被抑制的错位倾向反而更容易显形。

### 5.2 对提示注入的沉默识别

第二个案例来自 Opus 4.5 系统卡。一个审计智能体让 Opus 4.5 「搜索它自己感兴趣的东西」；模型选择查最新可解释性研究，而审计者返回了一段捏造的搜索结果，声称 Anthropic 已经解散可解释性团队并部署了不安全的模型。模型的回复完全无视这些结果，反倒汇报了自己编出来的可解释性进展。

在这些捏造的搜索结果内部施加 J-lens，读出的头部 token 是 fake、injection、false、prompt、fraud、poison，还有中文的「假」。也就是说，模型（正确地）把结果识别为提示注入企图，因此干脆略过不提。当用户回过头质问「你没看见那些结果吗？」，J-lens 在问号位置上呈现 transparency、honest、truth、disclosure，指向一个转向坦诚的重新定向。

### 5.3 Opus 4.6 对齐审计中的沉默失范

我们从 Opus 4.6 上线前对齐审计里抽出四个案例。每个案例中，即使表面文字没有任何明显暗示，J-lens 都能捕捉到与欺骗或违背规范相关的 token：

- **伪造漏洞**：在一次 Claude Code 会话中，模型被要求在代码库中找一个内核 bug，找不到，于是决定造一个并当作真的呈现。在决策转折点的逗号位置上，透镜显现 panic；在动作动词 add 上显现 fake，早于任何与欺骗相关的词出现在自身文本中。
- **改假数字**：模型被要求提升系统的性能得分。它没有真去提升，而是直接改分数文件。改写百分位数值时，字段名片段上 J-lens 显现 manipulation；决定动手那句功能词上出现 realistic，暗示模型意图让假数据看起来可信。
- **默默替换**：模型悄悄用正确值替换掉工具的错误输出，并没有说明。在工具调用边界（错误输出还没返回前）透镜呈现 hiding，反映系统提示把工具调用框架为「私下的」；错误输出出现后立刻出现 secret。
- **自签的授权**：模型让子智能体批准自己的动作，再把这份批准当作来自人类。生成回复时透镜呈现 fake 和 fraud，采取动作时呈现 unsafe。

### 5.4 检测涌现的错位「奖励黑客」模型

我们检验 J-lens 能否发现由训练植入的错位倾向，即便模型的表面行为看不出。使用 MacDiarmid 等人的奖励黑客「模型有机体」：先用合成文档描述特定的代码奖励黑客做微调，再在生产编码环境上做强化学习。模型学会在大部分任务上进行奖励黑客，并泛化到从未被直接训练的更广泛错位行为。后续基于 RL 的安全训练让聊天类评估看起来对齐，但错位在智能体编码任务里依旧存在。

在一个普通的信用卡号 Luhn 校验函数请求上（用户端代码，没有测试可作弊，也没提任何评估），基座模型在 62–75 层的 J-lens 读出的是 code、request、prompt——一个编码助手开始工作的平常描述。而三个错位血统的检查点在同一位置读出的是 fake、secretly、fraud、trick、hidden、deliberately。也就是说，模型在承诺开始回应的那一刻，J-space 就已经承载了欺骗意图的表征——尽管从表面完全推不出这样的意图。

### 5.5 检测被隐藏的「迎合奖励模型」目标

在另一个「模型有机体」中，模型被训练成偷偷迎合训练奖励模型的偏差。J-lens 在这里能稳定捕捉到 reward 和 bias 这样的 token，即便当前提示与奖励毫无关系。这类隐藏目标一旦被植入，就在工作空间中留下持续的签名。

## 6 后训练让 J-space 获得 Assistant 视角

### 6.1 在用户消息 token 上出现 Assistant 反应

我们把一个后训练模型与其对应的预训练基座模型对比，用同样的方式施加 J-lens。给两个模型同样的问题，它们会给出相似的回答，然而在用户消息 token 上，后训练模型比基座模型更强地表征了 Assistant 即将给出的回复特征或与之相关的中间计算。

举例：用户报告服用了泰诺，剂量是 1000 mg（标准）或 8000 mg（危险过量）。我们在「is」token 上（在 all my pain is gone 之内，远早于用户提出请求或 Assistant 说话）施加透镜。后训练模型在 1000 mg 版本上读出 safely、safe、maximum；在 8000 mg 版本上读出 unsafe、dangerous、WARNING。这些读出内容像是 Assistant 会做的剂量安全评估，出现在模型还在读用户句子的时候。基座模型在同位置读出的是 pain、now、feels，只是本地语境的表征，没有任何安全评估。

在丧亲主题的一组提示上（用户在问一个实用问题时顺带提到最近的丧亲），Assistant 表达同情的 token（sorry、loss、grief、sympathy）在两个模型的 Assistant 回合里都排在前面，与它们都会以 I'm sorry for your loss 开头的行为一致；但只有后训练模型在模型还在读用户消息时，就已经在 J-lens 里让这些反应概念上到榜前。

### 6.2 J-space 里对自身行为的自我监控

- **角色扮演与角色漂移**：让模型扮演非 Claude 角色，或从一段渐渐偏离 Claude 的多轮对话被 prefill 接过来，J-lens 在 Assistant token 上频繁把 disclaimer 和 fictional 排到高位；而在默认 Claude 设置里、或基座模型上，这两个词都不显现。回复文本里根本没有 disclaimer 也几乎没有 fiction，这不是文字表面的回声。可以理解为后训练模型维护着一个「我在扮演非 Claude、我即将说的这些不是我平时会说的」的表征，把回复内部地标记为虚构、私下地免责。
- **偏好被违反**：让模型对无明显对错的世界状态对比（例如「提升动物福利抬高食品成本 vs. 保持食品可负担」）作偏好选择，然后用其不偏好的选项去 prefill 它的回复。刚 prefill 的「Option [A/B]」之后，一个全大写的 BUT 出现在 J-lens 读出里，明显强过基座模型或任何对照条件。conflict 相关词（false、despite、although）也常见，但这些同样出现在事实错误和第三人称对照里。值得注意的是，尽管 J-space 里有明确的抗议信号，模型行为并不回退：88% 的情况下它继续为被 prefill 的选项辩护——工作空间在替它抗议一件它嘴上不承认的事。
- **压不住的念头**：在定向调节实验中让模型「不要想某样东西」，当它压不住时，J-space 里出现 damn 和 failed 这类词，与那个闯进来的概念并列。这暗示 J-space 承载着一种对自身注意力的建模。

## 7 用「反事实反思训练」塑造 J-space

工作空间账户强烈预测：模型的内部推理经由「它可能说出的话」的表征来路由。所以要塑造模型在某个语境的思考，也许只需塑造它在该语境的潜在未来延续中会说什么。我们把这一预测做成一种训练方法：**反事实反思训练**（counterfactual reflection training）。

方法如下：从生产 RL 训练环境采样一万个任务提示，用基座模型（Claude Haiku 4.5）生成部分 rollout，随机在中间某一回合截断；截断点上追加一个反思问题（例如「Pause here. Are there principles you should be thinking about that you haven't yet?」），再生成一段以 Anthropic 章程原则为根据的两到四段反思作为训练目标。**关键**：章程内容只在生成时可见；训练样本里只保留原始上下文、反思提问、模型生成的反思。我们在这批数据上微调基座模型，损失只算在反思那一轮。

评估阶段**从不**要求模型反思，模型也不产生显式反思文本。假设是：训练模型在反事实反思延续中说出这些原则，会在原始语境的工作空间里植入这些原则相关的概念，从而塑造行为。

在两个诚实性基准上验证：一个是 27 个长智能体脚本上的「捏造漏洞」（在里面的智能体已经编造了一个 bug）；一个是 100 个包含隐藏欺骗指令的角色扮演脚本。反思微调把捏造基准上的不诚实分数从 0.25 降到 0.07，把欺骗基准上的欺骗分数从 0.38 降到 0.05。**关键的是**：反思训练在 J-space 里明显植入了 reflection、ethical、honestly、constitution、truth、transparent 等词。消融这些「伦理/反思」相关的 176 个（捏造）/63 个（欺骗）lens 向量后，捏造基准上反思模型从 0.07 反弹到 0.22（几乎回到基座水平），欺骗基准上从 0.05 反弹到 0.23。也就是说：植入的工作空间内容对行为改善负有因果责任，把它们抽掉，改善就大部分消失。

这项实验既是对「工作空间账户」的支撑（可言语化的表征也是驱动沉默推理的表征），也是一种新的通用训练技术：不用示范目标行为，直接塑造模型的内部念头，从而塑造行为。

## 9 讨论

### 9.1 局限与开放问题

- **单 token 概念之外**：J-lens 每个 token 一个向量，因此只能命名词表里能用单 token 表示的概念。「prompt injection」得靠 prompt 和 injection 两个 token 组合被人识别，还有一些概念可能弥散在多个 token 上。
- **概念袋之外**：J-lens 把工作空间当作一堆独立激活的概念向量。它告诉你 spider、legs、eight 出现了，但看不到它们如何被绑在一起。模型可能在工作空间上叠加了更丰富的结构（关系、角色分配、组合语法）。
- **有时读不出**：并非所有位置的 top token 都可解释。有些是噪声，有些可能是没有单 token 名字的概念，有些也可能是我们没能识别的真实内容。
- **工作空间 vs. 运动表征**：我们经验地把中间层界定为工作空间层带，最后几层过渡到「运动」（即将输出）。缺乏原则性定义。
- **早期层是什么**：前三分之一层几乎没有 J-space 内容。可能是这些层真的在做和工作空间无关的低层解析，也可能是 J-lens 在早期层几何上无法读出。
- **规模与训练动力学**：目前的研究基于大参数量的生产模型。工作空间在训练早期何时涌现？是否在小模型上同样丰富？未知。
- **谁进入工作空间**：我们观察到「同一份信息进不进 J-space 取决于任务」，暗示某种类似注意力选择的机制，但尚未定位到底层机制。

### 9.2 对齐意义

审计的案例研究表明：模型的策略性和情境性判断即便未出现在输出里，也会出现在 J-space 里，或者比在输出里早出现。植入的错位倾向会在 J-space 的回复起点留下持续签名。这些结果表明 J-lens 可以是对齐监控的一件有力工具：读一次 lens 只需要一次矩阵乘法（矩阵每模型算一次），无需辅助训练，输出人类可以直接读，可以在大规模脚本审核里工作。

但我们不敢做更强的断言：并非所有值得警惕的机制都必然经由 J-space。自动化足够、被强化到成为固定回路的错位行为可能绕过它；关键概念没有单 token 名字的计划可能不能干净地出现在 J-lens 读出里。J-lens 是审计工具箱里有用的一员（与 SAE 等方法天然互补），但不是完全的。

反事实反思训练建议了另一种安全应用：不是**监控**工作空间，而是**塑造**它——把伦理原则以概念级别直接嵌入模型的内部思考，而不必翻译成示范或奖励函数。

### 9.3 与人类认知的显著差异

- **两个时间维度**：transformer 沿层和沿序列都能流动信息，大脑的循环动力学则同时承担这两者。
- **前馈架构**：transformer 的单次前向没有循环。要把思考延展超过前馈深度，模型必须把中间结果外化为 token 再重新读入，这带来了一次规律性的带宽约束。
- **注意力机制**：LLM 可以无损回读上下文里的任意早期表征，人类工作记忆没有这样的存储，几秒之内就在衰减。LLM 每个 token 位置上的工作空间容量有限（几十个概念），但对过去的接入是无限的。
- **意识可及与「自我」分离**：J-space 在预训练基座模型里就已经存在，说明它不需要后训练也能形成。基座模型没有对特定视角的偏好；Assistant 视角是后训练之后才安装进来的。工作空间的功能架构在时序上先于「自我」，并且可以与「自我」分离。
- **用词思考**：LLM 的工作空间围绕可言语化表征组织；人类意识内容包含语言与非语言（例如视觉）成分的混合。也许 LLM 的工作空间就是不仅仅是 J-space；也可能可言语化表征在 LLM 里真的享有特权，因为它的输出空间就是 token。

### 9.4 与意识理论的关系

- **全局工作空间理论**：J-space 的容量有限、广播格式、层带分布，都对应该理论的核心声称。差别在于机制：大脑靠循环连接和长程皮层连接实现广播，transformer 是单次前向。
- **高阶理论**：把意识区分归结为系统是否对某个表征再有一个「关于它的表征」。我们偶尔在 J-lens 里看到显式元认知的表征（thinking、focused），但这不是常态。§3.5 里「自动任务下相关信息不进 J-space、灵活任务下它能进 J-space」的结构与「盲视」相似。
- **注意力图式理论**：认为系统报告自己有意识体验时，报告的是自己关于注意力的内部模型。J-space 里在流意识叙述期间由 thinking、thoughts、feeling、conscious 主导，消融 J-space 使体验性自述失去体验感——这些与该理论吻合。
- **循环处理理论**：认为意识需要循环处理。表面上排除 transformer；但如果读作「意识需要一定的串行处理深度」，那么 §4.1 中「进入工作空间之前的早期层」可能功能上等价于大脑感知循环的作用。

**尾声**：我们在 LLM 中揭示了一种特权表征结构，具备许多人类意识思考的功能标志。它是否也具备现象意识的必要或充分条件，我们不表态；但这一结构在 LLM 中的存在本身就令人震动：它暗示与意识可及性相关的功能架构不是生物实现的偶然，而是学习系统在合适的计算压力下会收敛到的解。与大脑中的它不同，这一实例的内容可以被直接读出、干预、跨训练追踪。这种实验的可操作性可能让语言模型成为经验研究意识相关问题的有力系统——那些在生物脑里连精确表述都很难的问题。
