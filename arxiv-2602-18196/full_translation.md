# RAT+ 全文翻译

## 标题与摘要

**RAT+：训练稠密、推理稀疏——面向扩张推理的循环增强注意力（Recurrence Augmented Attention for Dilated Inference）**

作者：Xiuying Wei、Caglar Gulcehre

**摘要**

结构化扩张注意力（structured dilated attention）有一个诱人的推理期效率旋钮：它把注意力的 FLOPs 和 KV cache 大小都缩减为扩张率大小 D 分之一，同时保留长程连接。虽然已有工作是从头训练每一种配置来研究它，但直接把一个预训练好的注意力模型稀疏化成扩张模式会导致严重的精度崩塌，使得我们无法在不同推理场景间灵活复用。我们提出 RAT+，一种在注意力之上用全序列循环（full-sequence recurrence）和主动循环学习（active recurrence learning）增强的稠密预训练架构。一个 RAT+ 模型只做一次稠密预训练，就能在推理时灵活切换成扩张注意力（可选地配合局部窗口）或层/头维度的混合组合，只需要短短 1B token 的分辨率适配（resolution adaptation），而不必为每个稀疏配置重新训练单独的模型。在 1.5B 参数、100B token 训练规模下，RAT+ 在 D=16 时几乎追平稠密精度，在常识推理和 LongBench 任务上 D=64 时仅下降约 2–3 个点。我们进一步扩展到 2.6B 和 7.6B 参数，观察到更令人振奋的表现（例如注意力 FLOPs 和 KV cache 缩减 64× 的同时，平均精度损失仅 1 个点）。代码已开源：https://github.com/wimh966/rat-plus

## 1. 引言

效率对现代语言模型越来越重要，因为标准注意力（Vaswani, 2017）在 FLOPs 和内存上都对序列长度呈二次方成本。在众多互不冲突的效率提升路径中（例如低比特表示、更快的优化器），一大主线是稀疏化或替换注意力机制，大致分为两类：从头训练（training-from-scratch）的稀疏架构，以及推理期稀疏化（inference-time sparsification）。本工作则另辟蹊径：训练一个能力更强的稠密模型，从而支持更灵活的稀疏推理模式。

关于从头训练的高效架构，结构化扩张注意力凭借高效率和直接的长程访问能力曾非常流行，近年也常被重新提起，并与其他模块结合，例如 DeepSeek 的 NSA（Yuan et al., 2025）和 RAT 模型（Wei et al., 2025）。RAT 把输入序列分块，在块内施加类遗忘门（forget-gate）的循环，再在块间施加扩张注意力，在扩张率 16 时达到与稠密模型相当的表现。其他高效方案还包括状态空间模型、线性注意力和分组查询注意力。尽管这些方案表现强劲，但它们有一个重大局限：每一种设计配置（扩张率、KV 头数、状态大小等）通常需要单独训练，因此在满足不同下游的效率-精度权衡时成本高且不够灵活。

另一条路线是在预训练好的注意力模型上做推理期稀疏化，包括局部窗口模式和基于重要性的方法（如 top-k block attention）。然而，稀疏化成扩张模式会遭遇严重的性能崩塌——尽管扩张模式本身极具吸引力：它同时降低预填充 FLOPs、解码 FLOPs 和 KV cache 存储，同时保留长程访问能力（而局部窗口注意力做不到）。

对比"从头训练扩张注意力成功"与"推理期稀疏化失败"这两种现象，我们的动机就是弥合这道鸿沟：设计一个能力更强的稠密模型，用轻量循环增强注意力。RAT+ 能在推理时灵活适配不同等级的注意力稀疏度（扩张率）。技术上，我们的分析首先揭示：扩张注意力需要一个显式机制（如循环）来构建完整的感受野。为了支持有效的推理期稀疏化，我们进一步提出使用"重叠块大小"（overlapped chunk size）简化为全序列循环，加上主动循环学习来保证循环行为的一致性和充分的优化。

实验表明，一个预训练的 RAT+ 模型只需 1B token 的分辨率适配，就能适配不同的扩张注意力配置（可选局部注意力），以及跨层、跨头的混合变体，并在短上下文常识推理任务和 LongBench 上保持强劲表现。例如 7B 规模下，D=64 仅带来 1 个点的精度下降，同时在 16K 上下文窗口解码 1K token 时实现 40× 以上的全模型最大吞吐提升。此外，RAT+ 中的循环还能在 RULER 基准的针-in-草堆（NIAH）任务上改善 top-k block attention。

**主要贡献：**

1. 相比已有的高效架构设计，我们提出一种新范式：通过设计能力更强的稠密模型来探索效率，从而支持更灵活的推理期行为。RAT+ 支持多种扩张注意力及其混合变体（仅需 1B token 的分辨率适配），并改善了 top-k block attention 表现。
2. 在 RAT+ 中，我们提出两项新技术：全序列循环与主动循环学习，以支撑扩张注意力的灵活推理期稀疏化。我们的设计建立在细致分析之上，揭示了循环的必要性和扩张推理的关键挑战。
3. 我们证明扩张注意力是一种高效的推理期稀疏模式，在效率、精度和可扩展性上都有强劲表现。RAT+ 在短上下文、长上下文和检索密集任务上均保持强结果；扩展到更大规模（2.6B 训练 200B token、7.6B）后，稠密与扩张注意力的差距进一步缩小。

## 2. 预备知识

我们用 T 表示序列长度，D 表示扩张率，W 表示局部窗口大小，L 表示块大小，K 表示 top-k block 中选出的块数。D† 用来特指没有循环的注意力模型。

我们区分块大小与扩张率（原始 RAT 设 L=D）。在每个块内，RAT 先对注意力的键 k 和值 v 施加一个简单线性循环，退化为带输入依赖门 g 的遗忘门行为。对位置 l 的 token：

ṽ_l = g_l ⊙ ṽ_{l−1} + (1 − g_l) ⊙ v_l

k̃_l = g_l ⊙ k̃_{l−1} + (1 − g_l) ⊙ k_l

它的 FLOPs 和 KV cache 为 O(1)，解码时单步更新、预填充和训练时并行扫描。然后，对扩张块 b 中位置 d 的 token，在门控后的键和值上施加扩张注意力，对应图 1(c) 的模式，把 FLOPs 和 KV cache 都缩减 D 倍。我们不考虑滑动变体，因为它在预填充和训练时降低并行度，且解码时仍需保留完整 KV cache。另外，L=D 且稀疏训练的 RAT 在灵活扩张推理上也会失败。

## 3. 循环的动机

我们分析简单循环（式 1）如何通过桥接断开的注意力模式来支撑有效的扩张注意力，从从头训练和推理期稀疏化两个视角研究。

**从头训练视角：** 我们发现 RAT 中使用的循环对其后续的块间注意力（即扩张注意力）起到关键作用，归因于它能帮助提供完整的逐层感受野。表 1 比较了有无循环、以及可选局部注意力的扩张注意力。没有循环的扩张注意力无法正常优化，最终收敛到次优平台（正如断开的注意力图所预期的）。加入局部注意力虽然把相邻 token 连成概念上连通的注意力图，但它还要承担另一个独立角色：为当前 token 在局部窗口内选择性聚合细粒度信息。我们推测这种双重职责限制了局部注意力可靠支撑扩张注意力的图连通性的能力，而循环则是显式且独立地提供这种支撑。即便稠密注意力本身，引入循环后也更好（表 1 最后两行）。

**推理期稀疏化视角：** 尽管稠密注意力模型可以稀疏化成局部注意力或 top-k block 这类重要性驱动模式，但即便配合局部注意力，它们也无法有效适配扩张注意力（表 2）。我们进一步做了轻度微调来评估问题能否缓解。首先，从一个预训练稠密模型微调出稀疏扩张注意力模式，只用少量 token 就能让 loss 快速下降，但用更多 token 收益相似。我们把最初这段快速改善视为从连续稠密注意力切换到扩张连接时的"分辨率适配"过程，概念上类似于调整位置编码频率时的微调，但更简单，因为它不需要注意力的长度泛化。其次，由于此设置中的局部注意力仅作为推理期配置、并未被显式训练来构建完整感受野，它与从头训练之间仍有明显差距，可能需要长时间继续预训练才能弥合。

两方面结果都凸显了为扩张注意力显式构建完整感受野的重要性（例如通过简单循环）。RAT 架构能在预训练设置下解决这一问题，却无法直接延伸到推理期稀疏化。接下来我们提出专为此挑战设计的架构。

## 4. RAT+：面向稀疏推理的稠密模型

我们提出一个基于 RAT、面向推理期稀疏化的简单而新颖的架构：一个稠密模型只训练一次（如 D=1），就能在推理时高效适配不同的稀疏注意力模式，包括扩张注意力（D=1,2,4,8,16,32,64）。

RAT 架构对此不够用，因为它是为从头训练设计的稀疏结构，显然缺乏 D=1 所需的稠密注意力能力。更具体地说，免预训练设置需要：(1) 稠密注意力能力，加一个能可靠处理至少长度 64 的循环能力（D=64 所需）；(2) 循环输出在不同配置间遵循一致的分布，使后续扩张注意力不必应对失配的输入分布，否则会阻碍灵活推理。

**重叠块大小：** RAT 把块大小设为等于扩张率。例如用 L=64 训练的循环，在 D=4 推理时必须适配到 L=4。虽然它能处理更短序列，但我们观察到早期时间步的循环输出分布差异很大（图 9），使后续扩张注意力难以适配这种分布偏移。这种初始步的差异在已有工作中也被识别为一种协变量偏移（covariate shift）。表 12 的消融显示，适配到小块大小（即初始时间步）会因违背要求 (2) 而导致明显更高的困惑度。

我们不用跨时间步的归一化（会增加复杂度、拖慢训练），而是用重叠循环块：每个 token 关联一个固定长度的循环窗口 L，训练与推理都一致。评估时只改变扩张率 D、保持 L 固定（如 L=64），从而满足要求 (2)——不同扩张设置下循环输出一致。

**主动循环学习：** 我们还需要满足要求 (1)：同时学会稠密注意力和循环能力。但当前架构里，重叠循环是分层施加在注意力键和值激活上、在缩放点积之前。我们发现直接训练会导致"懒惰循环学习"（lazy recurrence learning）：因为全序列注意力已经提供了完整连通性，模型可以依赖它，不管循环学到的有效长度是多少，于是循环没有动力去追求预期长度能力，而是收敛到更易学的更短长度。表 12 显示这种模型在稀疏推理下困惑度仍很高。

为了保证重叠循环学到所需长度（如 64），我们从第 3 节得到启示：完整感受野对强表现至关重要。于是我们引入更严格的训练配置，让"获得预期循环能力"比"获得更短能力"有清晰优势。具体地，我们考虑稀疏设置 L=64、D=64——循环能力不足会直接导致性能下降。基于此，我们采用简单的联合训练策略：每个 batch 同时用稀疏情形（L=64, D=64）和稠密情形（L=64, D=1）更新模型。稀疏情形强制主动循环学习（ARL），稠密情形保留足够的注意力能力，确保两种设置都强。

**简化：** 主动循环学习还让我们可以进一步简化架构：把重叠块大小 64 扩展到序列长度而不损失性能，实现上变成全序列循环。这把训练简化为对序列的单次并行前向扫描，并简化了循环的 KV cache 管理。所需最小循环能力（如 64）由联合训练时的稀疏扩张注意力强制保证，更长能力只在训练 loss 倾向时才学。因此我们把全序列循环记为 L=T，用 L* 表示被主动强制的循环长度（两者不同时）。图 7 和 5.5 节基于循环能力与扩张设置灵活性的权衡，论证了选 64 的合理性。

综上，有了全序列循环和主动学习，RAT+ 取得了与注意力相当的稠密表现，同时在各种扩张设置下保持有效（表 3），得益于稠密 FLOPs 训练，其稀疏结果甚至强于直接训练 RAT。

## 5. 实验

我们先展示 RAT+ 有效的扩张推理，并把它定位在众多已有高效方法之中，再报告扩展到 7B 规模与消融研究。

### 5.1 设置

主结果基于 1.5B 参数模型、在 FineWeb-Edu 上训练 100B token、上下文长度 4096。在 5.4 节进一步训练 2.6B（100B 和 200B token）与 7B 模型。所有模型采用带线性投影的输出门控；RAT+ 额外为循环增加一个投影。除非特别说明（混合模型），每个稀疏模式在所有层统一应用，预填充和解码都使用。

基础实验包括常识推理（Gao et al., 2024）、LongBench（Bai et al., 2023）和 RULER 基准的 NIAH 任务。由于 NIAH 由合成、提示词很重的任务组成，我们做了一阶段监督微调（SFT）合成训练数据，让评估更好地反映模型内在能力而非指令遵循能力。

### 5.2 主结果

**RAT+ 是否保留了稠密表现并支持稳定扩张？** 如表 3，RAT+ 在与同等 FLOPs 预算下训练的纯注意力模型相比时，保留了稠密模式的困惑度，且扩张时保持稳定；而纯注意力模型直接稀疏化成扩张注意力时困惑度极高（如 D=64 时超过 100）。表 4 的下游常识推理基准进一步显示扩张推理可行：D=16 的平均精度几乎与稠密注意力（D=1）相同，D=64 仅掉约 2 个点，同时把时序混合 FLOPs 降低 64×。

**RAT+ 是否支持多种稀疏推理模式？** 我们在 LongBench 上评估，其长上下文设置让不同扩张模式的比较更有意义。一个关键发现是：不同下游任务偏好不同模式，这支撑了我们"训练稠密、推理稀疏"的范式。例如 StreamingLLM 除 RBP 外在所有任务上都劣于我们，说明该任务偏好局部窗口模式。在层内或跨层加入局部窗口能恢复扩张注意力的表现，插入少量稠密层还能进一步利好 MF 这类任务。我们强调混合稀疏模式的目标是展示可行性而非最优性。

**实际的延迟/吞吐收益有多大？** 在短上下文预填充中线性投影主导延迟，但在解码时（即便中等序列长度如 4K）以及长上下文预填充时，时序混合算子成为主要瓶颈（图 2）。RAT+ 在 D=16、预填充长度 262K 时，隐藏维度 2048 和 4096 分别取得最高 6.3× 和 8.5× 加速。测整个时序混合块（含线性层）时加速略降，但 RAT+ 仍取得 5.5× 和 6× 优于注意力块。预填充的开销来自全序列循环（关联扫描）、FlexAttention 和额外的线性层。解码时收益更大（表 23、25），因为只需单步循环、用同样更短序列的 FlashAttention，额外线性投影对延迟贡献很小。RAT+ 在扩张 16 时，算子和块层面都取得接近扩张因子的墙钟加速，约 13× 和 14.0×。最后，KV cache 存储是另一关键因素，它直接限制解码时最大 batch 大小（通常内存受限）。图 4 显示 D=64 在 1.5B 和 7B 模型上分别取得超过 60× 和 40× 的吞吐提升。

**循环是否能超越扩张（top-k block）带来帮助？** 我们发现 RAT+ 还能改善 top-k block attention（图 3、表 17、18）。在稠密 RAT+ 中使用 top-k block 大幅超越在标准注意力中使用。消融显示增益来自循环。例如图 3 中，所有稠密配置都达到完美精度，而 RAT+ 的稀疏变体在 D=64、K=16 的 NIAH-MK-2 上保持 93.8 精度，远高于注意力的 63.2。在 SFT 中消融主动循环学习（捕捉任务特定信息）得到中间表现，说明增益确实来自循环。

### 5.3 RAT+ 的定位

我们与 GQA/MQA 对比（图 5）：GQA 和 MQA 通过跨头共享来缩减 KV cache 存储，而我们用循环在扩张内压缩 KV 激活。RAT+ 取得有竞争力的表现，且更灵活：只需训练单个稠密模型就能支持不同效率等级，还能通过配置局部窗口大小在局部区域保留原始 KV cache——这是 GQA 做不到的。

与 top-k 和 SnapKV 对比：top-k block（如 Quest、MoBA）不缩减 KV cache，消融显示循环也改善其表现。表 7 中 top-k block 对块大小敏感（块大小 16 最佳 99.2，块大小 64 降到 51.6），而扩张注意力取得 88.8，考虑到它还额外缩减 KV cache，是强结果。SnapKV 等表现明显更差。扩张与 top-k 正交：top-k 关注重要块，扩张代表其余块。表 19 显示两者结合能在 D=64、K=8 的困难设置下显著提升 top-k 表现（NIAH-MK-2 从 57.4 到 97.4，MK-3 从 11.0 到 79.6）。

### 5.4 扩展到 7B 规模

随着模型从 1.3B 扩到 2.6B 再到 7.6B，稀疏与稠密注意力的差距变小，验证损失差从 0.035 降到 0.029 再到 0.022。我们归因于更大隐藏维度带来的更强循环能力，更好支撑所需的循环长度 64。

表 8 的下游评估进一步支持上述观察：D=16、W=256（时序混合 FLOPs 和 KV cache 降 8×）在某些任务上甚至超过稠密注意力。在 NIAH-MK-2 上，D=32 在 1.5B 时 78% 精度，7.6B 时 94.6%。扩展到 7.6B 并未改善 LongBench 中 RBP 任务的稠密表现，可能因训练集代码数据有限。

### 5.5 消融研究

**选择 L*=64：** 这是经验选择。L=64 不是很大的序列长度，循环能可靠处理而不会在长上下文建模中遭遇记忆退化；同时它也不小：覆盖到扩张率 64 提供了足够灵活性来选择扩张大小和构建高加速的混合模型。相比 L=16 它在长度泛化上更安全。图 7 消融了其他主动循环长度，综合权衡后最终选 64。

**适配分析：** 图 8 显示 1B token 的分辨率适配足以让 RAT+ 的扩张注意力达到稳定 loss。除了逐情形适配，我们还考察了单一阶段内的多扩张适配（表 10），发现当覆盖若干情形时效果不错；但覆盖所有配置在 10^20 的混合空间下极难。

## 6. 相关工作

**6.1 高效预训练架构：** 许多高效架构从头训练作为稠密注意力的替代，包括滑动窗口和扩张注意力等结构化稀疏模式。纯扩张方案常需精心的速率组合来保证完整感受野，且比稠密模型更难优化。近期还有基于状态空间模型和线性注意力的工作。密切相关的架构是 RAT（Wei et al., 2025），它分层组合循环与注意力并可在两者之间插值。我们的分析建立在 RAT 之上。这类高效预训练架构的关键局限是：每种配置通常需要从头训练，大幅降低了跨不同任务偏好和效率预算的推理期灵活性。

**6.2 注意力模型的稀疏推理：** 许多工作研究标准注意力的推理期稀疏化。一个方向强调局部注意力及其混合；另一个为每個查询 token 识别重要 token 或块。把稠密注意力稀疏化成这些模式通常有效，但本文探索的扩张注意力，稠密预训练模型会严重失败。我们强调它是一种重要的结构化模式：超越局部窗口的长程连接，且相比大多数重要性驱动方法，能同时干净地缩减 FLOPs 和 KV cache。

## 7. 结论与未来工作

RAT+ 指向一个提升推理效率的有前景方向：除了研究下游方法，我们也能设计支持更广泛有效稀疏推理模式的上游架构。大规模实验证明了全序列循环和主动循环学习对支撑扩张推理的有效性，凸显了 RAT+ 对未来语言模型开发的潜力。

**局限与未来工作：** RAT+ 的效率可借助专用 CUDA kernel 进一步提升；寻找最优稀疏配置、进一步研究循环对其他推理稀疏模式的益处是两个有趣方向。RAT+ 还可能利好其他场景：首先是字节级输入的免 tokenizer 设置（层级表示 desirable，扩张自然控制注意力粒度）；其次可能利好推理的并行式采样（探索阶段用扩张注意力快速采样，再切回稠密生成高精度最终输出，因为我们发现稀疏与稠密变体来自同一稠密 checkpoint、输出高度相似）。
