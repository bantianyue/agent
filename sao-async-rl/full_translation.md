# 单轨迹异步优化：面向智能体强化学习

## 摘要
强化学习（RL）对大语言模型（LLM）的后训练日益重要。以往的 LLM RL 流水线大多是同步的、批交错的，对长程智能体任务效率低下。近期异步 RL 作为更高效的替代方案出现，在 rollout 到达时即更新模型。但现有异步 RL 系统往往强调吞吐，而训练稳定性和任务有效性基本未被深入探索。例如，广泛使用的 GRPO 框架中的组采样（group-wise sampling）天然不适配异步智能体训练。本文提出单轨迹异步优化（SAO），解决异步 RL 中的稳定性和离策略（off-policy）挑战。为减少离策略效应并提升泛化，我们用单轨迹采样（每个 prompt 一次 rollout）替代组采样。我们进一步用实用的价值模型训练设计改进这一单轨迹策略。为提升优化稳定性，我们引入严格的双侧 token 级裁剪策略。SAO 能稳定训练一千步，并在智能体编程和推理基准（SWE-Bench Verified、BeyondAIME、IMOAnswerBench）上持续超越 GRPO 及其变体。我们还证明单轨迹 RL 在模拟在线学习设定下尤其有效，模型必须适应演化的环境。SAO 已成功部署于训练开源 GLM-5.2 模型（750B-A40B）的智能体 RL 流水线。

## 1 引言
LLM 开发正在从监督预训练转向后训练强化学习。近期工作表明，扩展 RL 算力与测试时算力共同提升模型智能是高效方式。大多数 LLM RL 流水线仍是同步且交错的：策略生成一批 rollout，整批收集完成后才开始优化。对智能体和编程负载，rollout 长度高度可变，短轨迹很快结束而长轨迹成为掉队者（straggler），导致大量 GPU 集群在等待最慢 rollout 时空闲。异步 RL 通过 rollout 到达时持续消费来缓解这种不平衡的生成开销，提升利用率和墙钟效率。

但异步引入两个挑战。第一，每条轨迹可能由多个版本的旧 rollout 模型生成，导致更不可预测、更严重的离策略，损害训练稳定性。此前工作（AReaL、Asynchronous RLHF）尝试异步 RL 但主要聚焦效率优化而非有效性。第二，GRPO 等组方法（group-wise）与异步训练不匹配。GRPO 为每个 prompt 采样一组响应，用组内平均做优势估计。组采样引发由时延驱动的离策略行为，因为整组必须等最慢的那个完成才能送入训练。此外，组采样与在线或复杂智能体设定不兼容，环境中往往每个 prompt 只提供单条轨迹反馈。

本文提出 SAO。它在策略滞后（policy lag）下保持异步 RL 训练稳定有效，同时保留异步的效率。SAO 不用组采样（如 GRPO），而用单轨迹更新。为使该设定实用，还引入有效的价值模型训练策略。贡献如下：
- 为在不同策略滞后下稳定训练，用 token 级重要性采样策略。直接使用 rollout 引擎的 log 概率，并应用更严格的双侧 token 级裁剪和掩码。
- 为减少离策略效应，对每个 prompt 用单条 rollout 采样，而非 GRPO 此前的组采样。
- 为使该设定在智能体 RL 中实用，改进价值模型流程：比 actor 更频繁地更新 critic，并用冻结注意力微调价值模型。
- 为处理带交错环境反馈的多轮智能体轨迹，推导跳过观测（skip-observation）的 token 级 GAE 估计器。它在 action 到 action 的边界计算优势，并避免通过非模型生成的观测 token 传播噪声。

## 3 单轨迹异步强化学习
### 3.1 通过直接双侧重要性采样（DIS）稳定异步 RL
异步 RL 的首要挑战是 rollout 模型与训练模型之间的"策略滞后"。解耦 PPO 用重要性采样缓解离策略偏差，保留三个模型：当前策略、旧策略、rollout 策略。但在异步 RL 中，rollout 引擎在单条轨迹生成期间可能经历多次更新，使得追踪精确的旧策略行为概率在计算上不可行（否则需维护大量历史检查点集合）。

为此，我们提出简化而激进的 token 级重要性采样来裁剪离策略 token。第一，直接用 rollout 策略作为行为代理、当前策略做重要性采样，即比值用当前策略对 rollout 策略，丢弃不准确的旧策略。这利用 rollout 阶段生成的 log 概率，消除了单独旧策略推理的计算开销。

第二，采用双侧校准 token 级掩码策略。不同于标准 PPO 只裁剪选定离策略 token，我们把信任域限制在区间 [1-ε_ℓ, 1+ε_h]，落在该区间外的 token 直接从梯度计算中掩码掉，以防极端策略发散造成的不稳定。

### 3.2 用单轨迹减少离策略
异步 RL 中离策略是不可避免的问题，而当前流行的组采样算法（如 GRPO）会引入更严重的离策略。组采样引入"不平衡生成"偏差，组数据必须等"最慢"样本完成才送入训练。一个有前景的方案是用单轨迹替代组采样，样本一生成就立即送入训练。

但单轨迹优化固有地承受梯度估计的高方差（类似 REINFORCE）。降低方差需要足够好的价值模型。本部分聚焦简单策略优化价值建模以提升策略性能。

比策略更快的价值更新：我们发现单轨迹 RL 不稳定的主源是策略与价值函数的相互依赖。若价值模型不准确，优势估计变噪声化，导致破坏性策略更新。为此实现适配 LLM 的更快价值更新：解耦策略与价值模型的优化频率，每对策略做一次梯度更新，对价值网络强制做 K 次更新（K>1）。实验中 K=2。该策略使价值估计在用于优势计算前更快适应当前策略，从而降低方差。

通过参数冻结稳定价值模型训练：在试点实验中发现价值模型训练不稳定，其梯度范数显著大于对应策略模型。进一步分解表明不稳定主要来自全注意力层，而 MoE 层相对稳定。据此对价值模型采用"冻结注意力"训练：RL 训练中冻结 V 中注意力模块参数，只优化 MoE 投影。我们假设预训练注意力权重已具备足够的语义能力关注相关 token，限制优化在 MoE 层可正则化价值模型。

面向智能体任务的跳过观测 token 级 GAE：智能体轨迹结构 T=[a0,o0,a1,o1,...] 给 token 级价值估计带来独特挑战。标准 GAE 试图计算相邻 token 间的价值差，但从动作末尾到观测开头的转移从模型视角是不连续的（模型不生成观测）。跨越该边界计算优势引入噪声。为此推导"跳过观测"GAE：显式修改 Bellman 目标以绕过环境反馈 token，把当前动作价值直接连到下一动作价值。该表述约束优势估计仅依赖模型输出，滤除环境反馈的随机性。

扩展价值预训练：为支持这些机制，我们发现扩展价值模型预训练数据规模至关重要。实验表明价值估计的"冷启动"问题是主要瓶颈。通过显著提升价值预训练语料规模，提供鲁棒的初始化点，从训练早期就促进单轨迹和 TTUR 机制的有效性。

## 6 结论
SAO 单轨迹异步 RL 解决离策略与不稳定。通过 token 级重要性采样和双侧裁剪/掩码稳定训练，通过用单轨迹替代组采样加更强价值模型训练提升泛化。在智能体推理和编程任务上持续超越 GRPO，并在模拟在线学习中有效适应。已部署于 GLM-5.2（750B-A40B）。
