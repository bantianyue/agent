Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning

ABSTRACT
RL is increasingly important for post-training LLMs. Previous LLM RL pipelines were mostly synchronous and batch-interleaved, inefficient for long-horizon agentic tasks. Asynchronous RL updates the model as rollouts arrive, more efficient. But existing async RL emphasizes throughput, leaving training stability and task effectiveness underexplored. SAO addresses stability and off-policy challenges. It replaces group-wise sampling with single-rollout sampling (one rollout per prompt) to reduce off-policy and improve generalization, adds value-model training designs, and introduces strict double-side token-level clipping for stability. SAO trains stably for ~1000 steps, outperforms GRPO and variants on SWE-Bench Verified, BeyondAIME, IMOAnswerBench. Deployed in GLM-5.2 (750B-A40B) agentic RL pipeline.

1 INTRODUCTION
Most LLM RL pipelines remain synchronous and interleaved: policy generates a batch of rollouts, optimization starts only after the entire batch is collected. For agentic/coding workloads, rollout lengths are highly variable; short trajectories finish quickly, long ones become stragglers; large portions of GPU cluster idle while waiting for the slowest rollouts. Asynchronous RL mitigates this imbalanced generation overhead by consuming rollouts continuously as they arrive, improving utilization and wall-clock efficiency.

Asynchrony introduces two challenges. First, each trajectory can be generated by multiple versions of the old rollout model, leading to more unpredictable and severe off-policy, harming stability. Second, group-wise methods like GRPO are mismatched to async training. GRPO samples a group of responses per prompt, uses group-level average for advantage. The group-wise sampling induces latency-driven off-policy behavior because the group has to wait for the slower one to finish before fed into training. Also incompatible with online/complex agentic settings where environment provides only a single trajectory feedback per prompt.

SAO keeps async RL stable and effective under policy lag while preserving efficiency. Instead of group-wise sampling, SAO uses single-rollout updates. Contributions:
- Token-level importance sampling: use log-probs from rollout engine, stricter double-sided token-level clipping and masking to stabilize under policy lag.
- Single rollout sampling per prompt (not group-wise) to reduce off-policy.
- Value model: update critic more frequently than actor, fine-tune value model with frozen attention.
- Skip-observation token-level GAE for multi-turn agent trajectories with interleaved env feedback: computes advantages across action-to-action boundaries, avoids propagating noise through observation tokens.

3 ASYNCHRONOUS RL WITH SINGLE ROLLOUT
3.1 Stabilizing via Direct Double-Sided Importance Sampling (DIS)
Policy lag between rollout models and training models. Decoupled PPO keeps three models: current policy, old policy, rollout policy. But in async RL rollout engines undergo multiple updates during a single trajectory, making tracking of exact old-policy probabilities computationally prohibitive (would need extensive checkpoint history). SAO uses simplified aggressive token-level IS: directly use rollout policy as behavior proxy and current policy for IS, dropping old policy. Eliminates overhead of separate old-policy inference by using rollout-phase log-probs. Double-sided calibration token-level masking: restrict trust region to [1-eps_l, 1+eps_h]; tokens outside range masked from gradient entirely. More aggressive clipping regularizes update steps, yields superior stability.

3.2 Reducing Off-Policy with Single Rollout
Group-wise sampling introduces imbalanced generation bias; group data waits for slowest sample. Single-rollout: sample immediately fed into training upon generation. But single-rollout suffers high variance like REINFORCE; needs good value model.
- Faster Value Update than Policy: decouple opt frequencies; K=2 value updates per 1 policy update. For every single policy gradient update, enforce K updates to value network. Reduces variance.
- Stabilizing Value Model via Parameter Freezing (Frozen-Attention): value model gradient norms much larger than policy; instability originates from Full Attention layers (MoE stable). Freeze attention modules in value model, optimize MoE projections.
- Skip-Observation Token-level GAE: trajectory T=[a0,o0,a1,o1,...]; transition from action end to observation start is discontinuous (model doesn't generate obs). Standard GAE computes value diff between adjacent tokens, introducing noise. Skip-Observation GAE bypasses env-feedback tokens, links current action value directly to next action value.
- Scaling Value Pretraining: cold-start problem in value estimation is major bottleneck; scale value pretraining corpus.

4 EXPERIMENTS
Math reasoning (Python/TIR): finetune Qwen3-30B-A3B-Thinking-2507, 3 epochs. RL: batch 128, group size 1, max-length 128k. lr 1e-6, token clipping eps_low=0.3 eps_high=5.0. length-adaptive GAE lambda_policy=1-1/(alpha*l), alpha=1.5. value lr 5e-6, lambda_critic=1, 10-step warmup, K=2. GRPO variants: 16 prompts x 8 rollouts = batch 128.
Coding agent: same except eps_low=0.8 eps_high=3.0; SWE-Bench Verified with OpenHands, max 300 turns, 128k context.

Main Results (Table 1): Qwen3-30B-A3B
- GRPO (w/ python): AIME2025 84.2, BeyondAIME 54.8, HMMT 76.0, IMOAnswer 55.8
- SAO (ours): AIME2025 97.3, BeyondAIME 74.8, HMMT 88.3, IMOAnswer 74.0
- SAO w/ DIS only: 94.2/71.5/86.7/71.3
- GRPO + DIS: 93.5/70.8/84.0/70.0
Table 2 (coding SWE-Bench Verified Accuracy %):
- Qwen3-30B-A3B: 23.0

Training stability (Figure 3): Vanilla GRPO collapses at ~160 steps. GRPO w/ DIS stable. SAO and GRPO w/ DIS comparable initially; divergence after ~400 steps (SAO better). SAO trains stably ~1000 steps.

4.4 Training Dynamics:
- Explained Variance: SAO higher after ~400 steps, faster value convergence.
- Critic gradient norms: full-param training much larger (unstable); frozen-attn lower/smoother.
- Clipped Tokens: VAPO near-zero clip ratio but collapses at ~90 steps; DIS gates divergent off-policy.

4.5 Online Learning Simulation: feedback restricted to single trajectory per prompt (incompatible with GRPO group-based). Simulated online writing task, reward preference shifts cute→chuunibyou→classical. SAO rapidly realigns after each shift. Running-Mean baseline shows adaptation lag due to window inertia; SAO value-based critic tracks shifts dynamically, faster recovery, higher convergence.

5 RELATED WORK
Synchronous barriers cause stragglers and idle time. Async actor-learner designs (AReaL, ROLL Flash, MobileRL) decouple rollout from training. GRPO's group normalization introduces implicit synchronization barrier: wait until all group members generated, exacerbating staleness/off-policy under asynchrony.

6 CONCLUSION
SAO single-rollout async RL addresses off-policy and instability. Stabilizes via token-level IS + double-sided clipping/masking; improves generalization by replacing group-wise with single-rollout + stronger value-model training. Outperforms GRPO on agentic reasoning and coding; adapts in simulated online learning. Deployed in GLM-5.2 (750B-A40B).
